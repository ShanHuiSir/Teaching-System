# 第 1 天 - 队长对接清单

## 今日目标

今天只做一件事：让三个人对系统范围、页面、接口和交付节奏达成一致，并让项目可以在本地启动。

## 今日最小版本

严格按照规划表收敛为：

1. 固定账号登录。
2. 学生管理入口。
3. 作品评价入口。
4. 导出成绩入口。
5. AI 评价先用假数据。

暂时不做：

- 多教师账号。
- 学生登录。
- 管理员。
- 复杂权限。
- 数据可视化。
- 多文件上传。
- 在线预览。
- 部署上线。

## 和 B 同学对接

你可以直接这样说：

> 你今天先不用接真实 AI。请先设计一个 FakeAIService，输入学生姓名和作品文件名，返回固定的分数、问题和评语。第 15 天前主流程只调用这个假 AI，等系统跑通后再替换真实接口。

B 同学今天交付：

- AI 返回字段清单。
- 一组固定模拟结果。
- 后续真实 AI 接口需要哪些参数。

建议字段：

| 字段 | 含义 |
| --- | --- |
| aiScore | AI 建议分数 |
| aiProblems | 存在问题 |
| aiComment | AI 评语 |

## 和 C 同学对接

你可以直接这样说：

> 你今天先按最小版本做页面，不要扩展太多功能。页面只需要登录页、学生列表页、作品评价页、导出入口。先保证表单和按钮位置清楚，后面再美化。

C 同学今天交付：

- 登录页草图。
- 学生列表页草图。
- 作品评价页草图。
- 基础 CSS 风格建议。

页面字段先按这些做：

- 登录页：账号、密码、登录按钮、错误提示。
- 学生列表页：学号、姓名、班级、操作。
- 作品评价页：学生、作品文件名、AI 评价按钮、AI 结果、最终分数、最终评语。
- 导出入口：导出 Excel 按钮。

## 队长今天要完成

1. 建项目结构。
2. 写 README。
3. 准备可启动 Web 骨架。
4. 明确两张数据库表字段。
5. 给 B/C 同学发任务。

## 今日验收标准

满足以下条件就算第 1 天完成：

1. 项目可以启动。
2. 浏览器能打开登录页。
3. 使用 `teacher / 123456` 能进入学生管理页。
4. 三个人知道自己第 2 天要做什么。
