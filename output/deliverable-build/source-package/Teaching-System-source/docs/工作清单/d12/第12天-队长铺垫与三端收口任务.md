## 6. 数据模型定版

以下模型已经落到后端实体、Repository、Controller、演示数据和测试。

### teaching_class

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `name` | 班级名 |
| `grade` | 年级 |
| `description` | 说明 |
| `created_at` / `updated_at` | 创建和更新时间 |

### student 调整

| 字段 | 说明 |
|---|---|
| `class_id` | 正式班级关系字段 |
| `class_name` | 快照和旧前端兼容字段 |

### assignment

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `title` | 作业标题 |
| `description` | 作业说明 |
| `work_type` | 作业类型 |
| `class_id` | 受理班级，若一作业多班级则需要中间表 |
| `class_name` | 班级名称快照 |
| `published_at` | 发布时间 |
| `due_at` | 截止时间 |
| `created_at` / `updated_at` | 创建和更新时间 |

### submission 调整

| 字段 | 说明 |
|---|---|
| `assignment_id` | 绑定提交所属作业 |
| `assignment_title` | 作业标题快照 |
| `updated_at` | 提交更新时间 |
| `returned_at` | 被打回时间，可选 |
| `return_reason` | 打回原因，可选 |

### submission_file

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `submission_id` | 关联提交 |
| `file_name` | 原始文件名 |
| `file_path` | 保存路径 |
| `file_size` / `content_type` | 文件元数据 |
| `file_role` | 文件角色，当前主文件为 `PRIMARY` |
| `primary_file` | 是否主文件 |
| `sort_order` | 排序 |
| `created_at` | 创建时间 |

### evaluation 调整

| 字段 | 说明 |
|---|---|
| `ai_created_at` / `ai_updated_at` | AI 评价时间 |
| `teacher_created_at` / `teacher_updated_at` | 教师评价时间 |
| `draft_score` / `draft_comment` | 云端草稿，可后置 |
