### 分层约定

| 层      | 包              | 职责                         |
|--------|----------------|----------------------------|
| 控制器    | `controller`   | 接收 HTTP 请求，参数校验，调用 Service |
| 服务接口   | `service`      | 定义业务能力抽象                   |
| 服务实现   | `service.impl` | 业务逻辑实现                     |
| 实体     | `entity`       | JPA 实体，对应数据库表              |
| 数据传输对象 | `dto`          | 请求体 / 响应体，不绑定数据库           |
| 数据访问   | `repository`   | Spring Data JPA 接口         |

### 分层约定

| 层 | 目录 | 职责 |
|----|------|------|
| 路由 | `router/` | 页面路由定义 + 导航守卫 |
| 布局 | `layouts/` | 应用外壳（顶栏 + 导航 + 内容） |
| 视图 | `views/` | 完整页面组件（每个路由一个） |
| 组件 | `components/` | 可复用 UI 片段 |
| 状态逻辑 | `composables/` | 共享响应式状态（单例模式） |
| 工具 | `utils/` | 基础设施（HTTP、Cookie、轮询等） |
| 样式 | `styles/` | 共享 SCSS（mixin、变量） |
| 类型 | `types.ts` | 共享 TS 接口 + InjectionKey |

## AI 服务结构

```
ai-service/
├── requirements.txt          # 统一依赖
├── config.py                 # 配置和环境变量读取
├── DocxConv/                 # FastAPI 主服务，包含 /api/preprocess、/api/evaluate/real、/api/evaluate/stream
├── Evaluator/                # DeepSeek 评分逻辑
├── ScreenshotProc/           # OCR 子工具
├── ArchiveProc/              # 压缩包处理子工具
└── RoadMap.md
```

当前状态：

- Py 侧统一预处理、真实评分和 SSE 流式评分接口已经存在。
- Java 后端上传后可配置调用 `/api/preprocess`，默认关闭。
- Java 评价主流程默认尝试真实 AI，Python 服务不可用时降级到 `FakeAIService`。
- 前端可通过 Vite 代理调用 `/api/evaluate/stream`，并将最终结果持久化到 Java `/api/submissions/{submissionId}/evaluation-result`。
