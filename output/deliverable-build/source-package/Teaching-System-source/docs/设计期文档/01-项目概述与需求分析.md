# 项目概述与需求分析

## 1. 项目名称

基于大模型的软件实训教学结果检查评价与报表系统

## 2. 项目背景

在软件实训教学过程中，教师需要检查大量学生作品，包括代码、实验报告和截图材料。传统人工评价方式耗时较长，评价标准不易统一，成绩统计和导出也较为繁琐。因此，本项目借助系统化管理和 AI 辅助评价，减轻教师工作量，提高评价效率和结果规范性。

## 3. 项目目标

用系统辅助教师完成学生作品管理、AI 辅助评价、教师复核、成绩统计和导出，减轻教师的工作量，提高效率。

## 4. 使用对象

当前阶段主要面向教师。（权重说明：现在只做教师端，功能暂不支持：学生登录、管理员、多教师权限）

## 5. 需求分析

### 5.1 功能需求

- 教师登录
- 学生管理
- 作品提交
- AI 辅助评价
- 教师复核评分
- 成绩统计
- 导出成绩

### 5.2 非功能需求

- 页面操作简单
- 流程清楚
- 数据结构清晰
- 后续方便接入真实大模型
- 后续方便扩展 Excel 导出

## 6. 技术栈

### 后端

- Spring Boot
