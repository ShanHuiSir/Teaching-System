`feature/c-ai` 主要改动：

- Py AI 服务新增 `/api/evaluate/stream` SSE 流式评分。
- Py AI 服务新增 `subjectType`、`rubric` 和 `dimensionScores`。
- Java `AIEvalRequest` 新增 `subjectType`、`rubric`。
- Java `EvaluationResult` 新增 `dimensionScores` 字段。
- Excel 导出新增 AI 分维度评分。
- `ReviewPage.vue` 新增评分主题选择与分维度评分展示。
- 新增样例文件和测试文件。

合并风险：

| 风险 | 说明 | 建议 |
| --- | --- | --- |
| 默认开启真实 AI | `application.properties` 将 `app.ai.real.enabled` 改为 `true`，8000 未启动时会降级 FakeAI，但日志会出现警告 | 演示环境可以开启；离线/CI 建议使用 `application-fake.properties` 或明确启动 Py 服务 |
| 前端展示维度评分 | `ReviewPage.vue` 会显示 `dimensionScores` | UI 风格保持 MagicBar/Niri 体系，改动不破坏主布局 |
| AI 日志文件入库 | 分支新增 `ai-service/logs/eval_results.jsonl` | 建议确认是否应跟踪日志文件，避免后续真实数据入库 |
| SSE 演示依赖 Py 服务 | `/api/evaluate/stream` 只有 Py 服务启动后可验收 | C 同学需提供启动命令和成功样例 |

结论：

- 从代码冲突和自动化检查看，`feature/c-ai` 具备合并基础。
- 从演示风险看，建议先由 C 同学启动 Py 服务并提供 `/api/evaluate/real` 和 `/api/evaluate/stream` 成功样例后再合入 `main`。
- 如果今晚必须合入，需要同步说明：真实 AI 默认开启，Py 服务未启动时 Java 会降级为 FakeAI。
