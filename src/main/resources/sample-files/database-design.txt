数据库课程设计：学生选课管理系统

一、需求分析
设计一个学生选课管理系统，支持学生信息管理、课程管理、选课与退课、
成绩录入与查询等功能。系统面向教务处管理员、教师和学生三类用户。

二、概念结构设计（ER 图说明）
核心实体及属性：
- 学生（Student）：学号、姓名、性别、班级、入学年份
- 教师（Teacher）：工号、姓名、职称、所属院系
- 课程（Course）：课程号、课程名、学分、学时、容量上限
- 选课记录（Enrollment）：选课时间、成绩

关系：
- 学生与课程：多对多（通过选课记录关联）
- 教师与课程：一对多（一位教师可教授多门课程）

三、逻辑结构设计（关键表 DDL）
CREATE TABLE student (
    id         BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_no VARCHAR(32) NOT NULL UNIQUE,
    name       VARCHAR(64) NOT NULL,
    gender     TINYINT,
    class_name VARCHAR(64),
    enroll_year INT
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE course (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    course_no   VARCHAR(32) NOT NULL UNIQUE,
    course_name VARCHAR(128) NOT NULL,
    credit      DECIMAL(3,1),
    hours       INT,
    capacity    INT,
    teacher_id  BIGINT,
    FOREIGN KEY (teacher_id) REFERENCES teacher(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE enrollment (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id  BIGINT NOT NULL,
    course_id   BIGINT NOT NULL,
    enroll_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    score       DECIMAL(5,2),
    FOREIGN KEY (student_id) REFERENCES student(id),
    FOREIGN KEY (course_id) REFERENCES course(id),
    UNIQUE KEY uk_student_course (student_id, course_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

四、索引优化
1. student 表：在 class_name 上建立索引，加速按班级查询
2. course 表：在 teacher_id 上建立索引，加速教师课程列表查询
3. enrollment 表：复合唯一索引 (student_id, course_id) 防止重复选课
