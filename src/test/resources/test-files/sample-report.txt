软件工程实训项目总结报告

一、项目概述
本项目为"在线教学评价系统"的 Web 端开发，采用前后端分离架构。
前端使用 Vue 3 + Element Plus，后端使用 Spring Boot 3，数据库选用 MySQL 8.0。
项目周期共 12 周，团队规模 4 人，本人负责后端 API 开发与数据库设计。

二、技术方案
后端采用分层架构：Controller → Service → Repository，通过 Spring Data JPA
实现数据持久化。API 文档使用 SpringDoc OpenAPI 3.0 自动生成。
文件上传采用 MultipartFile 接收，支持 DOCX、PDF、ZIP 等常见格式。
AI 评分模块通过 HTTP 调用 Python FastAPI 微服务，实现作业自动批改功能。

三、完成情况
已完成功能：学生管理、作业提交、文件上传、AI 自动评分、教师复核、成绩导出。
核心业务闭环已打通，前后端联调通过，Swagger 文档完整可交互。

四、遇到的问题与解决
1. 大文件上传时内存溢出 → 改用流式读取，限制单文件最大 50MB
2. AI 评分响应超时 → 加入重试机制与指数退避策略
3. 跨域请求被浏览器拦截 → 配置 CORS Filter 允许指定来源

五、总结与展望
通过本次实训，深入理解了企业级后端开发的全流程。后续可优化方向：
引入消息队列异步处理评分任务，减少用户等待时间；增加评分流式传输（SSE）
展示 AI 思考过程；完善单元测试与集成测试覆盖率。
