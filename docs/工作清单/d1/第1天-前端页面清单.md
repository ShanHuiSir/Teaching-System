# 第 1 天 - 前端页面清单

项目名称：基于大模型的软件实训教学结果检查评价与报表系统

第 1 天目标：先把前端页面拆清楚，明确每个页面要展示什么、有哪些操作、以后需要后端提供哪些数据。今天不追求写代码，重点是让三个人对系统长什么样、怎么演示达成一致。

## 一、核心演示流程

最低完成闭环：

1. 教师登录系统。
2. 进入学生管理页面，新增或查看学生。
3. 进入作品管理页面，给学生上传实训作品。
4. 进入作品详情，点击 AI 评价。
5. 系统显示 AI 评分建议、优点、问题、修改建议和教师评语草稿。
6. 教师修改最终分数和评语，并确认成绩。
7. 进入成绩统计页面，查看统计结果。
8. 导出 Excel 成绩表。

## 二、页面总览

| 页面 | 建议文件名 | 主要用途 | 优先级 |
| --- | --- | --- | --- |
| 登录页 | `login.html` | 教师账号密码登录 | 必做 |
| 首页 | `index.html` | 展示系统概览和快捷入口 | 必做 |
| 学生管理页 | `students.html` | 学生信息增删改查 | 必做 |
| 作品管理页 | `works.html` | 上传和查看学生作品 | 必做 |
| 评价详情页 | `evaluation.html` | AI 评价和教师复核 | 必做 |
| 成绩统计页 | `statistics.html` | 查看统计数据和导出报表 | 必做 |

## 三、页面详细说明

### 1. 登录页

文件名：`login.html`

页面目标：让教师输入账号和密码，登录进入后台。

页面内容：

- 系统标题。
- 账号输入框。
- 密码输入框。
- 登录按钮。
- 错误提示区域。

主要操作：

- 点击“登录”按钮。
- 登录成功后跳转到首页。
- 登录失败时显示错误提示。

需要的数据：

- 账号。
- 密码。

后续需要的接口：

- `POST /api/login`

## 2. 首页

文件名：`index.html`

页面目标：展示系统概览，让教师快速进入各功能页面。

页面内容：

- 顶部导航栏：首页、学生管理、作品管理、成绩统计、退出。
- 统计卡片：
  - 学生总数。
  - 已上传作品数。
  - 已完成 AI 评价数。
  - 已确认成绩数。
- 快捷按钮：
  - 新增学生。
  - 上传作品。
  - 查看成绩统计。

主要操作：

- 点击导航进入对应页面。
- 点击退出返回登录页。

需要的数据：

- 学生总数。
- 作品总数。
- 已评价数量。
- 已确认成绩数量。

后续需要的接口：

- `GET /api/dashboard`

## 3. 学生管理页

文件名：`students.html`

页面目标：管理学生基本信息。

页面内容：

- 顶部导航栏。
- 学生列表表格。
- 新增学生按钮。
- 编辑按钮。
- 删除按钮。
- 搜索框，可选。

学生表格字段：

| 字段 | 说明 |
| --- | --- |
| 学号 | 学生唯一编号 |
| 姓名 | 学生姓名 |
| 班级 | 所属班级 |
| 手机号 | 可选字段 |
| 操作 | 编辑、删除 |

新增或编辑学生时需要填写：

- 学号。
- 姓名。
- 班级。
- 手机号，可选。

主要操作：

- 查看学生列表。
- 新增学生。
- 修改学生信息。
- 删除学生。

后续需要的接口：

- `GET /api/students`
- `POST /api/students`
- `PUT /api/students/{id}`
- `DELETE /api/students/{id}`

## 4. 作品管理页

文件名：`works.html`

页面目标：上传和查看学生实训作品。

页面内容：

- 顶部导航栏。
- 上传作品表单。
- 作品列表表格。

上传作品时需要填写：

- 选择学生。
- 作品标题。
- 作品类型：代码、实验报告、截图、压缩包。
- 选择文件。
- 备注，可选。

作品表格字段：

| 字段 | 说明 |
| --- | --- |
| 学生姓名 | 作品所属学生 |
| 学号 | 学生编号 |
| 作品标题 | 本次提交名称 |
| 文件名 | 上传文件名 |
| 作品类型 | 代码、报告、截图、压缩包 |
| 上传时间 | 文件上传时间 |
| 评价状态 | 未评价、已评价、已确认 |
| 操作 | 查看、AI 评价 |

主要操作：

- 上传作品。
- 查看作品列表。
- 进入评价详情页。

后续需要的接口：

- `GET /api/students`
- `POST /api/works/upload`
- `GET /api/works`
- `GET /api/works/{id}`

## 5. 评价详情页

文件名：`evaluation.html`

页面目标：展示作品信息，调用 AI 评价，并让教师确认最终成绩。

页面内容：

- 顶部导航栏。
- 学生信息。
- 作品信息。
- 文件内容预览，可选。
- “开始 AI 评价”按钮。
- AI 评价结果区域。
- 教师复核区域。

AI 评价结果字段：

| 字段 | 说明 |
| --- | --- |
| 评分建议 | AI 给出的建议分数 |
| 优点 | 作品做得好的地方 |
| 问题 | 作品存在的问题 |
| 修改建议 | 给学生的改进方向 |
| 教师评语草稿 | AI 生成的评语 |

教师复核字段：

- 最终分数。
- 最终评语。
- 确认按钮。

主要操作：

- 点击“开始 AI 评价”。
- 查看 AI 评价结果。
- 修改最终分数。
- 修改最终评语。
- 确认成绩。

后续需要的接口：

- `GET /api/works/{id}`
- `POST /api/evaluations/ai/{workId}`
- `GET /api/evaluations/{workId}`
- `PUT /api/evaluations/{id}/confirm`

## 6. 成绩统计页

文件名：`statistics.html`

页面目标：展示成绩统计结果，并导出 Excel 成绩报表。

页面内容：

- 顶部导航栏。
- 统计卡片：
  - 平均分。
  - 最高分。
  - 最低分。
  - 已确认成绩数量。
- 等级分布：
  - 优秀：90 分及以上。
  - 良好：80-89 分。
  - 中等：70-79 分。
  - 及格：60-69 分。
  - 不及格：60 分以下。
- 成绩列表表格。
- 导出 Excel 按钮。

成绩列表字段：

| 字段 | 说明 |
| --- | --- |
| 学号 | 学生编号 |
| 姓名 | 学生姓名 |
| 班级 | 所属班级 |
| 作品标题 | 提交作品 |
| AI 建议分数 | AI 给出的分数 |
| 最终分数 | 教师确认后的分数 |
| 最终评语 | 教师确认后的评语 |
| 确认时间 | 成绩确认时间 |

主要操作：

- 查看统计信息。
- 查看成绩列表。
- 导出 Excel。

后续需要的接口：

- `GET /api/statistics`
- `GET /api/reports/export`

## 四、统一页面布局建议

所有后台页面建议使用相同布局：

- 顶部导航栏。
- 页面标题。
- 主要内容区域。
- 表格或表单。
- 操作按钮。

导航栏固定包含：

- 首页。
- 学生管理。
- 作品管理。
- 成绩统计。
- 退出。
