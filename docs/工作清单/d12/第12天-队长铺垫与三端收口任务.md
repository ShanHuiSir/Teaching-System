## 6. 数据模型改造草案

以下是明天队长要细化的方向，不要求 B/C 明天直接实现。

### class

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `name` | 班级名 |
| `grade` | 年级 |
| `description` | 说明 |
| `created_at` / `updated_at` | 创建和更新时间 |

### student 调整

| 字段 | 说明 |
|---|---|
| `class_id` | 替代长期依赖 `class_name` |
| `class_name` | 可短期保留为快照或兼容字段 |

### assignment

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `title` | 作业标题 |
| `description` | 作业说明 |
| `work_type` | 作业类型 |
| `class_id` | 受理班级，若一作业多班级则需要中间表 |
| `published_at` | 发布时间 |
| `due_at` | 截止时间 |
| `created_at` / `updated_at` | 创建和更新时间 |

### submission 调整

| 字段 | 说明 |
|---|---|
| `assignment_id` | 绑定提交所属作业 |
| `updated_at` | 提交更新时间 |
| `returned_at` | 被打回时间，可选 |
| `return_reason` | 打回原因，可选 |

### evaluation 调整

| 字段 | 说明 |
|---|---|
| `ai_created_at` / `ai_updated_at` | AI 评价时间 |
| `teacher_created_at` / `teacher_updated_at` | 教师评价时间 |
| `draft_score` / `draft_comment` | 云端草稿，可后置 |
