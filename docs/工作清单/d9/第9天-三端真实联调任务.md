# 第 9 天 - 三端真实联调任务

## 今日目标

第 9 天不再新增分散功能，重点把第 8 天已经形成的 Java、Vue、Py 三条线接成一条可演示链路：

```text
真实文件上传 -> Py 预处理 -> 真实 AI 评分 -> Java 落库 -> Vue 展示状态
```

## 当前基线

- Java 后端已经完成真实文件上传、文件元数据保存和可配置 Py 预处理转发。
- Vue 前端工程已经存在，作业提交页已开始调用 `POST /api/submissions/upload`。
- Py 侧 `DocxConv` 已提供 FastAPI `/api/preprocess` 和 `/api/evaluate/real`。
- Java 评价主流程仍默认使用 `FakeAIService`。
- Py 侧 `/api/preprocess` 已补齐 `renderStatus`、`renderEngine`、`renderWarnings`，仍需真实服务联调验收。

| 优先级 | 任务 | 具体要求 | 验收标准 |
| --- | --- | --- | --- |

| P0 | 明确字段映射 | 对齐 Py `aiScore/aiIssues/aiComment/status` 与 Java `EvaluationResult` | AI 返回结果能落库并被评价页读取 |
| P0 | 补自动化测试 | 使用 Mock Py 服务验证 Java 调 `/api/evaluate/real` | `mvn -q test` 通过 |
| P1 | 更新文档 | 补第 9 天任务清单、日报和问题记录 | 文档能说明已完成、未完成和风险 |
