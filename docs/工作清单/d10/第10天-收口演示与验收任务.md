## 演示推荐脚本

1. 打开系统首页，使用固定教师账号登录。
2. 进入学生管理，展示学生列表和搜索能力。
3. 进入作业提交，选择学生并上传一个简单 DOCX。
4. 展示上传结果中的文件名、文件大小、保存路径和预处理状态。
5. 如果 Py 服务开启，说明 Java 已调用 `/api/preprocess` 并保存结果。
6. 进入评价页，执行 AI 评价；若真实 AI Key 不可用，说明系统自动使用模拟评价兜底。
7. 教师复核分数和评语。
8. 查看统计摘要。
9. 导出 Excel 成绩表。
10. 最后说明当前 MVP 范围和后续优化项。
