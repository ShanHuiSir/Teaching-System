# 第 5-6 天合并 - 队长任务清单

## 明日定位

明天将第 5 天和第 6 天合并为一个工作日，主题为：

```text
前后端分离准备与启动
```

明天目标不是一次性完成前后端分离全部改造，而是先把稳定基线、接口清单、页面清单、分支规则和队友对接方式整理清楚，让 B 同学可以开始前端工程，C 同学可以开始后端接口适配。

## 分支与 PR 规则

| 规则 | 具体写法 |
| --- | --- |
| 基线分支 | 所有人先从最新 `main` 拉取 |
| 队长文档/整合分支 | `feature/d5-d6-leader-plan` |
| B 前端分支 | `feature/d5-d6-frontend-base` |
| C 后端分支 | `feature/d5-d6-api-base` |
| 禁止事项 | 不直接在 `main` 上写功能，不从旧的 `d4` 分支继续写 |
| PR 要求 | PR 描述必须写清楚改了哪些页面/接口、是否影响旧页面 |
| 合并顺序 | 先合 C 的接口基础，再合 B 的前端调用；如 B 只做静态工程结构，可先合 B |
