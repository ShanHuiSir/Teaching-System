# 教学评价系统 - 数据库表结构说明文档
> **数据库环境**：MySQL 8.0+  
> **字符集配置**：`utf8mb4` / `utf8mb4_unicode_ci`

本文档详细阐述了“教学评价系统”核心模块的数据库表结构设计。系统主要支持学生资料维护、学生作品在线提交、AI自动评审打分以及教师最终审核评语的一体化业务流程。

---

## 1. 学生表 (`student`)

* **业务说明**：存储学校学生的基础档案数据，作为系统各项业务的核心基准维度。
* **索引与约束**：
    * `PRIMARY KEY (id)`：主键聚簇索引，自增序列。
    * `UNIQUE KEY uk_sno (sno)`：唯一索引，确保每位学生的学号具有全局唯一性。

### 字段明细

| 字段名              | 数据类型           | 是否必填 | 默认值  |       其它属性       | 备注/说明 |
|:-----------------|:---------------|:----:|:----:|:----------------:|:------|
| **`id`**         | `BIGINT`       |  是   | *无*  | `AUTO_INCREMENT` | 主键ID  |
| **`sno`**        | `VARCHAR(32)`  |  是   | *无*  |        -         | 学号    |
| **`name`**       | `VARCHAR(64)`  |  是   | *无*  |        -         | 姓名    |
| **`major`**      | `VARCHAR(128)` |  是   | `''` |        -         | 专业    |
| **`class_name`** | `VARCHAR(128)` |  是   | `''` |        -         | 班级    |

---

## 2. 作品提交表 (`submission`)

* **业务说明**：记录学生上传、提交的作业或作品文件流物理存储元数据。
* **索引与约束**：
    * `PRIMARY KEY (id)`：主键聚簇索引，自增序列。
    * `INDEX idx_student_id (student_id)`：普通辅助索引，优化基于学生维度关联查询作品的检索性能。

### 字段明细

| 字段名                 | 数据类型            | 是否必填 |         默认值         |       其它属性       | 备注/说明                 |
|:--------------------|:----------------|:----:|:-------------------:|:----------------:|:----------------------|
| **`id`**            | `BIGINT`        |  是   |         *无*         | `AUTO_INCREMENT` | 主键ID                  |
| **`student_id`**    | `BIGINT`        |  是   |         *无*         |        -         | 学生ID（关联 `student.id`） |
| **`original_name`** | `VARCHAR(512)`  |  是   |         *无*         |        -         | 原始文件名                 |
| **`storage_path`**  | `VARCHAR(1024)` |  是   |         *无*         |        -         | 服务器存储位置 / 相对或绝对路径     |
| **`uploaded_at`**   | `DATETIME`      |  是   | `CURRENT_TIMESTAMP` |        -         | 上传时间                  |

---

## 3. 评价表 (`evaluation`)

* **业务说明**：存放 AI 生成的初步评审结果（分数、问题、评语）以及教师最终审核、修正的数据。
* **索引与约束**：
    * `PRIMARY KEY (id)`：主键聚簇索引，自增序列.
    * `INDEX idx_submission_id (submission_id)`：普通辅助索引，提速从作品记录关联查询AI及教师评价数据的多表连接。

### 字段明细

| 字段名                   | 数据类型           | 是否必填 |  默认值   |       其它属性       | 备注/说明                          |
|:----------------------|:---------------|:----:|:------:|:----------------:|:-------------------------------|
| **`id`**              | `BIGINT`       |  是   |  *无*   | `AUTO_INCREMENT` | 主键ID                           |
| **`submission_id`**   | `BIGINT`       |  是   |  *无*   |        -         | 提交ID（关联 `submission.id`）       |
| **`ai_score`**        | `DECIMAL(5,2)` |  否   | `NULL` |        -         | AI 建议分数（例如 85.50）              |
| **`ai_issues`**       | `TEXT`         |  否   | `NULL` |        -         | AI 发现的具体问题（大文本）                |
| **`ai_comment`**      | `TEXT`         |  否   | `NULL` |        -         | AI 综合评语                        |
| **`teacher_score`**   | `DECIMAL(5,2)` |  否   | `NULL` |        -         | 教师最终评分                         |
| **`teacher_comment`** | `TEXT`         |  否   | `NULL` |        -         | 教师人工评语                         |
| **`status`**          | `TINYINT`      |  是   |  `0`   |        -         | 状态：`0`-未评价，`1`-AI已评价，`2`-教师已确认 |
