# 设计期文档目录

设计期文档用于说明系统在开发前和原型阶段的整体设计，重点回答“系统做什么、给谁用、怎么用、页面有哪些、后续怎么实现”。

## 文档清单

| 序号 | 文档 | 说明 |
| --- | --- | --- |
| 01 | `01-项目结构.md` | 说明仓库目录、前后端文件位置和文档目录 |
| 02 | `02-业务流程设计.md` | 说明教师从登录到导出成绩的完整流程 |
| 03 | `03-数据库设计.md` | 说明核心数据表和字段 |
| 04 | `04-接口设计总体方针.md` | 说明接口设计原则，详细接口以 Swagger 为准 |
| 05 | `05-页面设计.md` | 说明各页面的内容、作用和跳转关系 |
| 06 | `06-组件交互设计.md` | 说明页面组件之间的交互流程 |
| 07 | `07-文件命名规范.md` | 说明 HTML、CSS、Java 文件等命名方式 |
| 08 | `08-标识符命名规范.md` | 说明类名、方法名、变量名、接口路径等命名规范 |

## 维护原则

- 设计变化时更新对应文档。
- 页面原型和业务流程必须保持一致。
- 文档里要区分“当前原型阶段”和“后续实现阶段”。
- 真实 AI、Excel 导出等未完成能力不能写成已完成。
