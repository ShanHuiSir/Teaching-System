# 设计期文档目录

设计期文档用于说明系统当前设计基线和关键约定，重点回答"系统做什么、给谁用、怎么用、页面有哪些、后续怎么实现"。

当前代码主线已经进入 Vue 3 SPA 阶段。业务页面以 `/dashboard`、`/classes`、`/assignments`、`/review` 为准；旧 Thymeleaf 页面、独立学生页、独立导出页和旧 Sidebar 仅存在于历史记录中。

## 维护原则

- 设计变化时更新对应文档。
- 页面、路由和业务流程必须保持一致。
- 文档里要区分"当前主线"和"历史记录"。
- 真实 AI、真实文件上传、Excel 导出、SSE 流式评分等能力按 `main` 实际实现状态描述。
