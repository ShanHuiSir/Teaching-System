# 设计期文档目录

设计期文档用于说明系统在开发前和原型阶段的整体设计，重点回答"系统做什么、给谁用、怎么用、页面有哪些、后续怎么实现"。

## 维护原则

- 设计变化时更新对应文档。
- 页面原型和业务流程必须保持一致。
- 文档里要区分"当前原型阶段"和"后续实现阶段"。
- 真实 AI、真实文件上传等未完成能力不能写成已完成；已完成的 Excel 导出等能力也要及时校准状态。
