# 07-组件交互设计

## 交互目标

组件交互设计用于说明页面中按钮、表单、表格和结果区域之间如何配合，保证 HTML 原型和后续功能实现的交互逻辑一致。

---

## 全局组件：可收纳侧边栏

所有页面（登录页除外）共享左侧可收纳侧边栏。

### 组件结构

```
┌─ md-sidebar ──────────────────┐
│ md-sidebar__header            │
│   md-sidebar__brand           │  ← 品牌名 + 折叠按钮
│   md-sidebar__toggle (#sidebar-toggle)
├───────────────────────────────┤
│ md-sidebar__nav               │
│   md-sidebar__nav-item × 4    │  ← 学生管理 / 作品提交 / 作品评价 / 导出成绩
├───────────────────────────────┤
│ md-sidebar__actions           │
│   .logout-link                │  ← 退出按钮
└───────────────────────────────┘
```

### 交互流程

```text
页面加载
 → 读取 localStorage('sidebar-collapsed')
 → 若为 'true' → 侧边栏折叠（64px，仅图标）+ body 添加 has-sidebar--collapsed
 → 若为 'false' 或不存在 → 侧边栏展开（240px）
 → 页面 body 的 padding-left 随侧边栏宽度联动

点击折叠按钮 (#sidebar-toggle)
 → 切换 md-sidebar--collapsed 类
 → 切换 body 的 has-sidebar--collapsed 类
 → 写入 localStorage('sidebar-collapsed', true/false)

点击导航项 (md-sidebar__nav-item)
 → 跳转至对应页面
 → 目标页面通过 th:classappend 高亮当前页的导航项

点击退出按钮 (.logout-link)
 → 弹出退出确认对话框 (#logout-dialog)
 → 取消 → 关闭对话框，聚焦退出按钮
 → 确认 → 跳转至 /（登录页）
 → ESC 或点击遮罩 → 关闭对话框
```

### 涉及文件

| 层 | 文件 |
|---|---|
| 模板片段 | `templates/fragments/sidebar.html`（`th:fragment="sidebar(activePage)"`） |
| 调用页面 | `students.html`、`works.html`、`evaluation.html`、`export.html` |
| 样式 | `style.css`（`.md-sidebar`、`.md-sidebar--collapsed`、`body.has-sidebar` 等） |

### 技术要点

- 侧边栏通过 `th:replace` 引入，`activePage` 参数控制当前页高亮：
  ```html
  <th:block th:replace="~{fragments/sidebar :: sidebar(activePage='students')}"></th:block>
  ```
- `th:classappend` 只在匹配时追加 `active` 类，不匹配时追加空字符串（无效果）
- 折叠状态通过 CSS transition 平滑过渡（`var(--md-sys-duration-medium)`）
- 移动端（≤768px）默认折叠，展开时文字自动隐藏

### 交互流程

```text
当前阶段（原型）

   → 表格实时更新
```

## 作品提交页

### 组件列表

| 组件 | HTML 选择器 | 状态 |
|---|---|---|
| 状态文字 | `#work-status`（`.md-page-header__status`） | **动态更新（JS）** |
| 学生选择 | `#student-select`（`select.md-field__input`） | **动态加载（JS）** |
| 提交表单 | `#work-form`（`.md-form-grid`） | **已对接 POST /api/submissions** |
| 作品列表表格 | `#work-table-body`（`.md-table tbody`） | **动态渲染（JS）** |
| 评价按钮（每行） | `.md-btn--tonal[href^="/evaluation"]` | 带查询参数跳转 |

### 交互流程

```text
页面加载 (initPage)
 → GET /api/students → 填充 #student-select 下拉
 → GET /api/submissions → 渲染 #work-table-body
 → 若有 URL 参数 studentId → 预选对应学生

提交作品 (form submit)
 → 阻止默认提交
 → 收集表单数据，studentId 转为 Number
 → POST /api/submissions (JSON)
 → 成功：重置表单，状态文字显示作品标题，刷新作品列表
 → 失败：状态文字变红显示错误消息

点击"评价"
 → 跳转 /evaluation?submissionId=...&studentName=...&fileName=...
```

### 组件列表

| 组件 | HTML 选择器 | 状态 |
|---|---|---|
| 学生信息区 | `.md-info-grid` | **静态占位**（张三 / 2026001 / student-work.zip） |
| AI 评价按钮 | `Step 1 .md-btn--filled` | **占位（无 JS）** |
| AI 评分展示 | `.md-score` | 静态占位（85 分） |
| AI 问题列表 | Step 2 `<ol>` | 静态占位（三条问题） |
| AI 评语 | Step 2 `<p>` | 静态占位 |
| 教师最终分数 | `input[type="number"]` | 静态占位（value="85"） |
| 教师最终评语 | `textarea` | 静态占位 |
| 保存评价按钮 | `Step 3 .md-btn--filled` | **占位（无 JS）** |

### 交互流程

```text
当前阶段（原型）
  Step 1 - 学生与作品信息 → 静态展示
  Step 2 - AI 评价结果 → 静态展示（85 分 / 三条问题 / 综合评语）
  Step 3 - 教师复核 → 输入框可编辑，保存按钮无响应

后续阶段（待实现）
  载入页面
   → 从 URL 参数读取 submissionId
   → GET /api/submissions/{submissionId}/evaluation 获取已有评价

  点击"执行 AI 评价"
   → POST /api/submissions/{submissionId}/evaluate
   → Step 2 动态渲染 AI 结果（覆盖静态占位数据）

  点击"保存最终评价"
   → 读取教师分数和评语
   → POST /api/submissions/{submissionId}/teacher-review
   → 提示保存成功
```

## 退出确认对话框

所有带侧边栏的页面共享退出确认对话框。

### 组件结构

```html
#logout-dialog (.md-dialog-overlay)
  .md-dialog
    .md-dialog__icon    (警告图标)
    .md-dialog__title   ("确认退出")
    .md-dialog__body    ("退出后需要重新登录...")
    .md-dialog__actions
      #logout-cancel    (取消按钮)
      #logout-confirm   (确定退出按钮)
```

### 交互流程

```text
点击 .logout-link → 移除 .hidden → 对话框显示，聚焦取消按钮
点击 #logout-cancel → 添加 .hidden → 关闭，聚焦退出按钮
点击 #logout-confirm → location.href = '/' → 跳转登录页
点击遮罩 (.md-dialog-overlay) → 关闭对话框
按 ESC → 关闭对话框
```
