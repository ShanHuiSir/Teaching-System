# 组件交互设计

## 交互目标

组件交互设计用于说明页面中按钮、表单、表格和结果区域之间如何配合，保证 HTML 原型和后续功能实现的交互逻辑一致。

## 学生管理页

```text
新增学生表单
 -> 点击“新增学生”
 -> 学生列表刷新
```

主要组件：

- 学号输入框
- 姓名输入框
- 班级输入框
- 新增按钮
- 学生列表表格
- 编辑/删除按钮

## 作品提交页

```text
选择学生
 -> 填写作品信息
 -> 点击“提交作品”
 -> 作品列表出现新记录
 -> 点击“进入评价”
```

主要组件：

- 学生选择框
- 作品标题输入框
- 作品类型选择框
- 文件名或文件选择控件
- 作品列表表格
- 进入评价按钮

## AI 评价与教师复核页

```text
作品信息展示
 -> 点击“AI 评价”
 -> 显示 AI 分数、问题和评语
 -> 教师填写最终分数和评语
 -> 点击“确认评分”
 -> 保存最终评价
```

主要组件：

- 作品信息区
- AI 评价按钮
- AI 结果展示区
- 教师最终分数输入框
- 教师最终评语文本框
- 确认评分按钮

## 成绩统计页

```text
读取已确认成绩
 -> 展示统计卡片
 -> 展示成绩明细表
 -> 进入导出页面
```

主要组件：

- 学生总数卡片
- 作品提交数卡片
- AI 已评价数卡片
- 教师已确认数卡片
- 平均分卡片
- 成绩明细表

## 导出成绩页

```text
选择导出条件
 -> 点击“导出 Excel”
 -> 系统生成成绩文件
```

当前阶段只做原型展示，后续再实现真实 Excel 文件下载。
