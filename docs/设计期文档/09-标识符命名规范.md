# 09-标识符命名规范

## 总体原则

- 标识符**见名知意**，不缩写、不拼音。
- 同类标识符使用一致的命名方式。
- 不同层次（Java、URL、SQL、CSS）有各自的约定，互不混用。

---

## 包名

**全小写，无分隔符。** 复合词直接拼接。

```
com.teachingeval.controller
com.teachingeval.service.impl
com.teachingeval.dto
com.teachingeval.entity
```

| 规则 | 示例 |
|---|---|
| 缩写整体小写 | `dto`（非 `DTO`）、`impl`（非 `Impl`） |
| 单数名词 | `controller` 而非 `controllers` |

---

## 类 / 接口 / 记录

**PascalCase + 层次后缀。** 后缀标识类在架构中的角色。

### 后缀规则

| 类型 | 后缀 | 示例 |
|---|---|---|
| Spring Boot 入口 | `*Application` | `TeachingSystemApplication` |
| 配置类 | `*Config` | `OpenApiConfig` |
| REST 控制器 | `*Controller` | `StudentController` |
| 全局异常处理 | `*ExceptionHandler` | `ApiExceptionHandler` |
| 服务接口 | `*Service` | `AIService` |
| 服务实现 | `{接口名}`（放 `impl/` 包） | `FakeAIService implements AIService` |
| 数据访问接口 | `*Repository` | `StudentRepository` |
| JPA 实体 | 无后缀 | `Student`、`WorkSubmission` |
| 接口入参 | `*Request` | `AIEvalRequest`、`TeacherReviewRequest` |
| 接口出参 | `*Response` | `StatisticsSummaryResponse` |

### 命名细则

| 规则 | ✅ 正确 | ❌ 错误 |
|---|---|---|
| 类名与文件名一致 | `StudentController.java` 内 `public class StudentController` | 文件名与类名不同 |
| 首字母缩写全大写 | `AIEvalRequest` | `AiEvalRequest` |
| 多词实体无后缀 | `WorkSubmission` | `WorkSubmissionEntity` |

### 示例对照

```
请求:  AIEvalRequest            → POST /api/submissions/{submissionId}/evaluate 的入参
请求:  TeacherReviewRequest     → POST /api/submissions/{submissionId}/teacher-review 的入参
响应:  StatisticsSummaryResponse → GET /api/statistics/summary 的出参
实体:  Student                  → student 表
实体:  WorkSubmission           → submission 表
实体:  EvaluationResult         → evaluation 表
服务:  StudentService           → 学生管理业务
服务:  EvaluationService        → 评价业务逻辑
接口:  AIService                → AI 评价能力抽象
实现:  FakeAIService implements AIService → AI 评价模拟
```

## 方法名

**camelCase + 动词前缀。** 前缀表达操作意图。

### 前缀含义

| 前缀 | 含义 | 示例 |
|---|---|---|
| `list` | 查询列表 | `listStudents()`、`listSubmissions()` |
| `get` | 查询单体 | `getEvaluation()`、`getSummary()` |
| `getBy` | 按某字段查询 | `getBySubmissionId()` |
| `create` | 新建 | `createStudent()`、`createSubmission()` |
| `delete` | 删除 | `deleteStudent()` |
| `save` | 保存 | `saveTeacherReview()` |
| `findBy` | 数据库查询（Repository 层） | `findBySubmissionId()` |
| `countBy` | 条件计数（Repository 层） | `countByStatusGreaterThanEqual()` |
| `existsBy` | 存在性检查（Repository 层） | `existsByStudentNo()` |
| `validate` | 校验（private 辅助） | `validateScore()` |
| `is` | 布尔判断 | `isAiEvaluated()`、`isBlank()` |

### 规则

| 规则 | ✅ 正确 | ❌ 错误 |
|---|---|---|
| 单个动词 + 名词 | `createStudent()`、`getSummary()` | `evaluateAndSave()`（已被修正为 `evaluate()`） |
| 不加冗余主语 | `listStudents()` | `studentServiceList()` |
| Repository 方法遵循 Spring Data 命名 | `findBySubmissionId` | `searchBySubmissionId` |

## 变量 / 字段

**camelCase，禁止匈牙利命名法和下划线。**

### 示例

```java
// Entity 字段
private Long id;
private String studentNo;
private String studentName;
private String className;
private BigDecimal aiScore;
private String aiIssues;
private LocalDateTime submittedAt;

// DTO 字段
private String studentName;
private String fileName;
private BigDecimal teacherScore;

// 局部变量
EvaluationResult result = aiService.evaluate(request);
List<BigDecimal> confirmedScores = ...
```

### 规则

| 规则 | ✅ 正确 | ❌ 错误 |
|---|---|---|
| 缩写保持小写 | `aiScore`、`studentId` | `AIScore`、`studentID` |
| 无需类型前缀 | `name`、`count` | `strName`、`iCount` |
| 无下划线 | `studentName` | `student_name` |
| ID 后缀全大写 | `studentId`、`submissionId` | `studentID`（不统一） |

## 常量

（当前项目暂无命名常量，此节为后续开发规范）

**全大写蛇形命名。**

```java
public static final int MAX_STUDENT_COUNT = 100;
public static final String DEFAULT_PASSWORD = "123456";
```

状态码应以 `enum` 替代 magic number：

```java
public enum EvaluationStatus {
    PENDING(0, "未评价"),
    AI_EVALUATED(1, "AI 已评价"),
    TEACHER_CONFIRMED(2, "教师已确认");
}
```

## URL 路径

**全小写，复数名词，连字符分隔。**

### REST API (`/api/*`)

| 规则 | 示例 |
|---|---|
| 资源用复数名词 | `/api/students`、`/api/submissions` |
| 嵌套子资源 | `/api/submissions/{submissionId}/evaluate` |
| 多词用连字符 | `/api/submissions/{submissionId}/teacher-review` |
| 路径变量用小驼峰 | `{submissionId}` 而非 `{submission_id}` |

### 页面路由（无 `/api` 前缀）

| 规则 | 示例 |
|---|---|
| 单数名词或动词 | `/login`、`/evaluation`、`/export` |

### 禁止

| ❌ 错误 | ✅ 正确 |
|---|---|
| `/api/TeacherReview`（大写+驼峰） | `/api/submissions/{submissionId}/teacher-review` |
| `/api/students/{student_id}`（下划线） | `/api/students/{id}` 或 `{studentId}` |
| `/api/student_list`（下划线+动词） | `/api/students` |

## 数据库标识符

**表名和列名全小写 snake_case。**

```sql
CREATE TABLE submission (
    id              BIGINT  NOT NULL AUTO_INCREMENT,
    student_id      BIGINT  NOT NULL,       -- student + id
    student_name    VARCHAR(64)  NOT NULL,  -- student + name
    submitted_at    DATETIME NOT NULL,      -- submitted + at
    PRIMARY KEY (id),
    INDEX idx_student_id (student_id)       -- 索引名: idx_{字段名}
);
```

| 标识符类型 | 命名方式 | 示例 |
|---|---|---|
| 表名 | 小写单数 | `student`、`submission`、`evaluation` |
| 列名 | 小写 snake_case | `student_id`、`ai_score`、`submitted_at` |
| 主键索引 | `PRIMARY KEY` | 自动 |
| 普通索引 | `idx_{字段名}` | `idx_student_id` |
| 唯一索引 | `uk_{字段名}` | `uk_student_no` |

## 属性键

**小写点分层次 + 连字符。** 遵循 Spring Boot 标准风格。

```properties
server.forward-headers-strategy=framework
springdoc.api-docs.path=/v3/api-docs
springdoc.swagger-ui.path=/swagger-ui
```

## CSS 类名

**BEM 风格，`md-` 前缀，全小写连字符。**

```
.md-card                       # Block（组件）
.md-card__body                 # Element（子元素）
.md-btn--filled                # Modifier（变体）
.md-form-grid--2               # Modifier
```

| BEM 部分 | 分隔符 | 含义 | 示例 |
|---|---|---|---|
| Block | `md-{name}` | 独立组件 | `.md-btn` |
| Element | `__` | 组件内部元素 | `.md-card__body` |
| Modifier | `--` | 外观/状态变体 | `.md-btn--danger` |

---

## HTML ID

**全小写连字符。** 用于 JavaScript 操作 DOM。

| ✅ 正确 | ❌ 错误 |
|---|---|
| `logout-dialog` | `logoutDialog` |
| `student-table-body` | `studentTableBody` |
| `work-form` | `workForm` |

> **已知问题**：当前代码中 `students.html` 和 `works.html` 部分 ID 仍使用驼峰（`studentTableBody`、`workForm`），应统一为连字符。

## 检查清单

- [ ] 类名有正确的层次后缀（Controller / Service / Repository）？
- [ ] DTO 按流向使用了 `Request` 或 `Response` 后缀？
- [ ] 方法名是 `{动词}{名词}` 格式，无复合动词？
- [ ] URL 路径全小写、复数名词、连字符？
- [ ] 数据库列名 snake_case，索引名 `idx_` / `uk_` 前缀？
- [ ] CSS 类遵循 `md-{Block}__{Element}--{Modifier}` BEM 风格？
- [ ] 无拼写缩写（`no` 而非 `number` 除外）、无拼音？
