# 标识符命名规范

## Java 类名

Java 类名使用大驼峰命名。

示例：

```text
Student
WorkSubmission
EvaluationController
FakeAIService
```

## Java 方法名和变量名

方法名和变量名使用小驼峰命名。

示例：

```text
listStudents
createStudent
studentNo
className
teacherScore
```

## 数据库表名

数据库表名使用小写英文和下划线。

示例：

```text
student
submission
ai_evaluation_result
```

## 数据库字段名

字段名使用小写英文和下划线。

示例：

```text
student_no
class_name
submission_id
teacher_score
teacher_comment
```

## 接口路径

接口路径使用小写英文，统一以 `/api` 开头。

示例：

```text
/api/students
/api/submissions
/api/evaluate
/api/statistics/summary
```

## 页面元素 ID

页面元素 ID 使用小驼峰命名。

示例：

```text
studentForm
studentTableBody
evaluationForm
finalScore
```
