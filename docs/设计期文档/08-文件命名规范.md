# 文件命名规范

## 总体原则

- 文件名要能表达用途。
- 同一类文件保持同一种命名风格。
- Markdown 文档使用中文名称，前面加两位序号。
- Java 文件使用大驼峰命名。
- HTML、CSS、接口路径使用小写英文。

## Markdown 文档

设计期文档采用：

```text
序号-文档名称.md
```

示例：

```text
01-项目概述与需求分析.md
02-业务流程设计.md
```

## HTML 文件

HTML 原型文件采用小写英文：

```text
login.html
index.html
students.html
works.html
evaluation.html
statistics.html
export.html
```

## CSS 文件

样式文件采用小写英文：

```text
style.css
```

## Java 文件

Java 类名使用大驼峰：

```text
Student.java
StudentController.java
StudentService.java
StudentRepository.java
```

## SQL 文件

数据库脚本使用小写英文：

```text
schema.sql
```
