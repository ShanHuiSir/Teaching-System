# 数据流说明

## 总体数据流

```text
学生信息
 -> 作品提交
 -> AI 评价结果
 -> 教师最终评价
 -> 成绩统计
 -> 成绩导出
```

## 1. 学生信息数据流

教师在学生管理页录入学生信息：

- 学号
- 姓名
- 班级

系统保存到 `student` 表。后续作品提交时通过学生 ID 关联学生。

## 2. 作品提交数据流

教师在作品提交页选择学生并填写作品信息：

- 作品标题
- 作品类型
- 文件名或文件
- 备注

系统保存到 `submission` 表，并生成作品提交 ID。

## 3. AI 评价数据流

教师在 AI 评价页点击“AI 评价”：

```text
submissionId
 -> AIService
 -> AIEvaluationResult
 -> ai_evaluation_result
```

当前阶段由 `FakeAIService` 返回模拟结果，包括：

- AI 建议分数
- AI 发现的问题
- AI 评语

## 4. 教师复核数据流

教师参考 AI 结果后填写：

- 教师最终分数
- 教师最终评语

系统更新 `ai_evaluation_result` 表中的教师评价字段，并将状态改为教师已确认。

## 5. 成绩统计数据流

成绩统计页读取学生、作品和评价结果数据，统计：

- 学生总数
- 作品提交数
- AI 已评价数
- 教师已确认数
- 平均分

## 6. 导出成绩数据流

导出成绩功能以后读取教师已确认的评价结果，生成 Excel 成绩表。当前阶段先完成原型和功能规划。
