# 10-数据流说明

## 总体数据流

```
学生信息 (Student)
  │
  ▼
作品提交 (WorkSubmission)
  │
  ▼
AI 评价 (FakeAIService → EvaluationResult)
  │
  ▼
教师复核 (TeacherReviewRequest → EvaluationResult 更新)
  │
  ▼
成绩统计 (StatisticsSummaryResponse)
  │
  ▼
成绩导出 (ExportService → Excel 文件流)
```

三张数据库表的关系：

```
student (1) ──── (N) submission (1) ──── (1) evaluation
```

## 1. 学生信息 → student 表

### 页面操作

### 数据流

```

  Body: { "studentNo": "2026001", "name": "张三", "className": "软件231" }
    │
    ▼
StudentController.createStudent(@RequestBody StudentRequest request)
    │
    ▼

    │
    ▼

```

## 3. AI 评价 → evaluation 表

### 页面操作

教师在评价页（`evaluation.html`）对某次提交触发 AI 评价。

### 数据流

```
POST /api/submissions/{submissionId}/evaluate
  Body: { "studentName": "张三", "fileName": "实验报告.docx" }
    │
    ▼
EvaluationController.evaluate(@PathVariable Long submissionId, @RequestBody AIEvalRequest request)
    │
    ▼
EvaluationService.evaluate(Long submissionId, AIEvalRequest request)
    │
    ├─ SubmissionRepository.findById(submissionId)     → 校验提交存在
    ├─ AIService.evaluate(request)                      → 调用 AI 评价
    │     │
    │     └─ FakeAIService.evaluate(AIEvalRequest request)
    │           │
    │           └─ 返回硬编码 EvaluationResult:
    │               aiScore = 82.50
    │               aiIssues = "1. 结构不够清晰...\n2. 缺少核心论点..."
    │               aiComment = "整体完成度较好..."
    │               status = 1
    │
    ├─ EvaluationRepository.findBySubmissionId(submissionId)
    │     │
    │     ├─ 存在 → UPDATE (复用已有记录)
    │     └─ 不存在 → INSERT (新建记录)
    │
    └─ EvaluationRepository.save(saved)
          │
          └─ INSERT/UPDATE evaluation SET
               submission_id = ?, ai_score = ?, ai_issues = ?, ai_comment = ?, status = 1
               │
               ▼
             返回 EvaluationResult（status = 1，AI 已评价）
```

### 关键逻辑：INSERT 还是 UPDATE？

```
EvaluationRepository.findBySubmissionId(submissionId)
    .orElseGet(EvaluationResult::new)
```

- 首次评价：库中无记录 → `new EvaluationResult()`（id = null）→ `save()` 执行 INSERT
- 重新评价：库中已有记录 → 查出的实体有 id → `save()` 执行 UPDATE

### 涉及文件

| 层          | 文件                                                  |
|------------|-----------------------------------------------------|
| Controller | `EvaluationController.java`                         |
| Service    | `EvaluationService.java`                            |
| AI 接口      | `service/AIService.java`                            |
| AI 实现      | `service/impl/FakeAIService.java`                   |
| Repository | `EvaluationRepository.java`                         |
| Entity     | `entity/EvaluationResult.java`（映射 `evaluation` 表） |
| 入参 DTO     | `dto/AIEvalRequest.java`                            |

## 4. 教师复核 → evaluation 表更新

### 页面操作

教师在评价页（`evaluation.html`）参考 AI 结果后，填写教师分数和评语。

### 数据流

```
POST /api/submissions/{submissionId}/teacher-review
  Body: { "teacherScore": 88.00, "teacherComment": "整体完成较好，建议继续完善代码注释。" }
    │
    ▼
EvaluationController.saveTeacherReview(@PathVariable Long submissionId, @RequestBody TeacherReviewRequest request)
    │
    ▼
EvaluationService.saveTeacherReview(Long submissionId, TeacherReviewRequest request)
    │
    ├─ 校验：已存在 AI 评价，否则抛 "请先完成 AI 评价"
    ├─ DTO 校验：teacherScore 不为空且 0~100
    ├─ DTO 校验：teacherComment 不为空
    │
    ├─ evaluation.setTeacherScore(request.getTeacherScore())
    ├─ evaluation.setTeacherComment(request.getTeacherComment())
    ├─ evaluation.setStatus(2)   ← 教师已确认
    │
    └─ EvaluationRepository.save(evaluation)
          │
          └─ UPDATE evaluation SET teacher_score = ?, teacher_comment = ?, status = 2 WHERE id = ?
              │
              ▼
            返回 EvaluationResult（status = 2，教师已确认）
```

### 涉及文件

| 层          | 文件                               |
|------------|----------------------------------|
| Controller | `EvaluationController.java`      |
| Service    | `EvaluationService.java`         |
| Repository | `EvaluationRepository.java`      |
| Entity     | `entity/EvaluationResult.java` |
| 入参 DTO     | `dto/TeacherReviewRequest.java`  |

## 5. 成绩统计 → 聚合查询

### 页面操作

教师进入成绩统计页（后端生成统计，前端展示）。

### 数据流

```
GET /api/statistics/summary
    │
    ▼
StatisticsController.getSummary()
    │
    ▼
StatisticsService.getSummary()
    │
    ├─ StudentRepository.count()                                        → studentCount
    ├─ SubmissionRepository.count()                                     → submissionCount
    ├─ EvaluationRepository.countByStatusGreaterThanEqual(1)            → aiEvaluatedCount
    ├─ EvaluationRepository.countByStatusGreaterThanEqual(2)            → teacherConfirmedCount
    ├─ EvaluationRepository.findAll()
    │     │
    │     └─ 筛选 status >= 2 的记录 → 计算 teacherScore 平均值
    │
    └─ 返回 new StatisticsSummaryResponse(studentCount, submissionCount,
           aiEvaluatedCount, teacherConfirmedCount, averageTeacherScore)
```

### 涉及文件

| 层          | 文件                                                                |
|------------|-------------------------------------------------------------------|
| Controller | `StatisticsController.java`                                       |
| Service    | `StatisticsService.java`                                          |
| Repository | `StudentRepository`、`SubmissionRepository`、`EvaluationRepository` |
| 出参 DTO     | `dto/StatisticsSummaryResponse.java`                              |

## 7. Python AI 评价服务（ai-service）

### 架构定位

`ai-service/` 是独立 Python HTTP 服务，最终替代 `FakeAIService` 成为真实 AI 评价引擎。当前 Java 端使用 `FakeAIService`（硬编码模拟数据），真实 AI 环境启动 Python 服务后，切换到 `HttpAIService` 通过 HTTP 调用。

```
Java (EvaluationService)
  │
  ├─ FakeAIService          ← 当前开发/演示模式（硬编码返回）
  │
  └─ HttpAIService          ← 真实 AI 模式（待实现）
        │  POST /api/evaluate
        ▼
   Python ai-service (Flask :5000)
        │
        ├─ ArchiveProc       ← 解压学生提交的压缩包
        ├─ DocxConv          ← DOCX → 结构化 JSON / 图片
        └─ ScreenshotProc    ← 截图 OCR → 文本 + bbox
```

### HTTP 契约

```
POST /api/evaluate    （Python 端）
  Request:  { "studentName": "张三", "fileName": "实验报告.docx" }
  Success:  { "aiScore": 82.50, "aiIssues": "...", "aiComment": "...", "status": 1 }
  Error:    { "message": "错误原因" }
```

### 预处理工具

| 工具 | 功能 | 输入 | 输出 |
|---|---|---|---|
| ArchiveProc | 压缩包解压 + 文件分类 | ZIP/RAR/7z | 文件清单 + 目录结构 |
| DocxConv | DOCX 转结构化数据 | .docx 文件 | JSON（段落/标题/图片引用） |
| ScreenshotProc | 截图 OCR | PNG/JPG 截图 | 文本行 + bbox 坐标 JSON |

三个工具各自独立，通过 `pyproject.toml` 管理依赖，统一由 `app.py` 调度。

### Java 侧接入计划

1. 新建 `HttpAIService implements AIService`，注入 `RestTemplate`
2. 配置 `ai-service.base-url=http://127.0.0.1:5000`
3. 通过 `@Profile` 或配置切换 `FakeAIService` / `HttpAIService`
4. `FakeAIService` 保留作为离线演示兜底

## 异常处理

所有 Service 层抛出的 `IllegalArgumentException` 由 `ApiExceptionHandler` 统一拦截：

```
IllegalArgumentException → 400 Bad Request → { "message": "错误原因" }
```

| 触发场景          | 异常消息                 |
|---------------|----------------------|
| 评价时提交不存在      | "作品提交不存在"            |
| 教师复核前未做 AI 评价 | "请先完成 AI 评价"         |
| 教师分数为空        | "教师分数不能为空"           |
| 教师分数低于 0      | "教师分数不能低于0"          |
| 教师分数高于 100    | "教师分数不能超过100"        |
| 教师评语为空        | "教师评语不能为空"           |
| 查询不存在的评价      | "评价结果不存在"            |
