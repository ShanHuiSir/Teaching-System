# 06-页面设计

## 概述

系统共 5 个 HTML 页面，均为 Thymeleaf 模板，存放于 `src/main/resources/templates/`。样式统一遵循 Material Design 3 规范（`style.css`）。

除登录页为独立布局外，其余 4 个页面通过 `th:replace` 共享同一侧边栏片段（`fragments/sidebar.html`）。

---

## 页面清单

| 页面名称 | 文件名 | 路由 | 主要功能 |
|---|---|---|---|
| 登录页 | `login.html` | `/` | 教师输入账号密码登录 |
| 学生管理页 | `students.html` | `/students` | 查看学生列表、搜索、新增学生 |
| 作品提交页 | `works.html` | `/works` | 选择学生、提交作品信息、查看作品列表 |
| 作品评价页 | `evaluation.html` | `/evaluation` | AI 评价 + 教师复核（三步工作流） |
| 导出成绩页 | `export.html` | `/export` | 导出成绩 Excel |

### 页面跳转关系

```text
/login (登录页，无侧边栏)
   ↓ 登录成功
/students ──┬── /works ──┬── /evaluation
            │            │
            └── /export ←┘
            
侧边栏导航连通全部 4 个业务页面
```

## 登录页

**路由**：`/`（GET）、`/login`（POST）  
**布局**：独立居中卡片（`body.login-page` → `.login-card`），无侧边栏

### 组件

| 组件 | 说明 |
|---|---|
| 系统名称 | "教学评价系统" + 副标题 |
| 账号输入框 | `input[name="username"]`，autocomplete |
| 密码输入框 | `input[type="password"]`，autocomplete |
| 登录按钮 | `button[type="submit"].md-btn--filled` |
| 错误提示 | `.login-error`，Thymeleaf `th:if="${error}"` 条件渲染 |

## 作品评价页

**路由**：`/evaluation`

### 布局（三步工作流）

```
┌─ 侧边栏 ─┐  ┌─ md-page ──────────────────────────────────┐
│          │  │ 作品评价                                    │
│  导航    │  │ ┌─ Step 1: 学生与作品信息 ─────────────────┐ │
│          │  │ │ 姓名│学号│班级│文件    [执行 AI 评价]    │ │
│  退出    │  │ └─────────────────────────────────────────┘ │
│          │  │ ┌─ Step 2: AI 评价结果 ────────────────────┐ │
│          │  │ │ 85 / 100 分                              │ │
│          │  │ │ ┌ 发现问题 ─┐ ┌ 综合评语 ──────────────┐ │ │
│          │  │ │ │ 1. ...    │ │ 整体完成度较好...       │ │ │
│          │  │ │ │ 2. ...    │ │                         │ │ │
│          │  │ │ └───────────┘ └────────────────────────┘ │ │
│          │  │ └─────────────────────────────────────────┘ │
│          │  │ ┌─ Step 3: 教师复核 ──────────────────────┐ │
│          │  │ │ 最终分数 [85]  最终评语 [textarea]      │ │
│          │  │ │ [保存最终评价]                          │ │
│          │  │ └─────────────────────────────────────────┘ │
└──────────┘  └─────────────────────────────────────────────┘
```

### 组件

| 组件 | 选择器 | 状态 |
|---|---|---|
| 学生信息网格 | `.md-info-grid`（4 项信息） | 静态占位 |
| AI 评价按钮 | Step 1 `.md-btn--filled` | 占位无 JS |
| AI 分数 | `.md-score__value` | 静态占位 "85" |
| AI 问题列表 | Step 2 `<ol>` | 静态占位 3 条 |
| AI 综合评语 | Step 2 `<p>` | 静态占位 |
| 教师分数 | `input[type="number"]` | 静态占位 value="85" |
| 教师评语 | `textarea` | 静态占位 |
| 保存按钮 | Step 3 `.md-btn--filled` | 占位无 JS |

## 全局共享组件

### 可收纳侧边栏

- 文件：`templates/fragments/sidebar.html`
- 引入方式：`th:replace="~{fragments/sidebar :: sidebar(activePage='...')}"`
- 展开 240px / 折叠 64px，折叠状态通过 `localStorage` 持久化
- 导航项：学生管理、作品提交、作品评价、导出成绩
- 底部操作：退出按钮 → 弹出确认对话框

### 退出确认对话框

- 所有带侧边栏页面共享（`#logout-dialog`）
- 取消 / 确定 / ESC / 遮罩关闭

---

## 样式规范

- CSS 文件：`src/main/resources/static/style.css`
- 设计体系：Material Design 3 B 端风格
- 组件前缀：`md-`（`.md-card`、`.md-btn`、`.md-table` 等）
- BEM 命名：Block `__` Element `--` Modifier
- 响应式：≤768px 侧边栏默认折叠，≤480px 页面头部纵向排列
