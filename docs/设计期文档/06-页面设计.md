# 06-页面设计

## 概述

前端为 Vue 3 单页面应用（SPA），使用 TypeScript + SCSS + Vite 8 构建。所有页面通过 Vue Router 管理路由，MainLayout 提供统一的外部框架（顶栏 MagicBar + 左侧导航栏 + 右侧工具栏）。

## 页面清单

| 路由                 | 页面组件 | 名称 | 说明 |
|--------------------|----------|------|------|
| `/login`           | `LoginPage.vue` | 登录 | 三层卡片动画（欢迎 → Cookie 管理 → 密钥登录） |
| `/dashboard`       | `DashboardPage.vue` | 仪表盘 | 统计概览、评分分布图表、趋势图 |
| `/review`          | `ReviewPage.vue` | 作业审批 | 三列滑动布局（作业列表 → 预览 → 批改表单） |
| `/classes`         | `ClassesPage.vue` | 班级管理 | 班级 CRUD + 花名册管理 |
| `/assignments`     | `AssignmentsPage.vue` | 作业管理 | 作业 CRUD + Excel 导出 |
| `/forbidden`       | `ForbiddenPage.vue` | 403 | 未登录提示页 |
| `/loading`         | `LoadingPage.vue` | 加载 | 过渡加载动画（含调试按钮） |
| `/:pathMatch(.*)*` | `NotFoundPage.vue` | 404 | 页面未找到 |

### 路由守卫

- 检查 `auth_token` Cookie
- 需要认证的页面（`/dashboard`、`/review`、`/classes`、`/assignments`）：无 token → 重定向 `/forbidden`
- 已登录访问 `/login` 或 `/forbidden` → 重定向 `/`
- 认证页面通过 `<KeepAlive>` 保持状态

### 页面跳转关系

```
/      ──→ /login
           ├── /dashboard
           ├── /review
           ├── /classes
           ├── /assignments
           ├── /forbidden    (无 token)
           └── /:pathMatch   (任意不匹配路径)
```

## 登录页

**路由**：`/login`  
**布局**：独立居中卡片，无 MainLayout 外壳

三层卡片动画：

| 层 | 内容 |
|----|------|
| 欢迎 | 系统名称 + 副标题 + 登录按钮 |
| Cookie 管理 | 三类 Cookie 偏好设置（必要/偏好/草稿），支持单类别清除 |
| 密钥登录 | 账号 + 密码 + 记住我 + 登录按钮 |

当前使用硬编码凭据（`teacher` / `123456`），登录后写入 `auth_token` Cookie，800ms 模拟延迟。

### 路由逻辑

```text
登录成功 → 设置 auth_token Cookie → router.push('/')
已登录用户访问 → router.replace('/')
```

## 仪表盘

**路由**：`/`  
**布局**：MainLayout 内，单面板全宽

### 区域

| 区域 | 内容 |
|------|------|
| 统计卡片行 | 待审批数、已提交数、学生总数、平均分 |
| 班级统计 | 各班级的提交率和审批率条形图 |
| 作业类型统计 | 各类型的提交数和平均分 |
| 评分分布 | AI 评分 vs 教师评分的双色对比柱状图 |
| 审批趋势 | 按日期展示的作业提交曲线 |
| 评分对比 | 各班 AI 评分 vs 教师评分的分布分布 |

### 交互

- 仪表盘面板显示可通过 Cookie 记忆（`dash_*` 偏好）
- 点击"刷新"手动拉取最新数据
- MagicBar 显示问候语（随机古诗 + 时间段 + 待批改数量）

## 作业审批

**路由**：`/review`  
**布局**：MainLayout 内，三面板滑动布局

```
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ Panel 1 (滑动)          │ Panel 2 (滑动)          │ Panel 3 (滑动)          │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • Tab: 发布的/提交的作业│ • 作业详情              │ • 批改表单              │
│ • 搜索框                │   - 学生信息            │   - 返回/应用 AI 评价   │
│ • 作业类型 / 学期分组   │   - AI 评分+问题+评语   │   - 分数调节器 + 输入框 │
│ • 提交列表（状态徽章）  │   - 附件预览            │   - 教师评语编辑器      │
│                         │   - 草稿恢复提示        │   - 提交批改按钮        │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Tab 1 - 发布的作业

- 按作业类型分组（如实验报告、代码作业），来源为 `/submissions` 数据聚合
- 展示提交进度（X/全班人数 · %）、审批进度、发布日期、截止日期
- "全部作业"入口展示所有提交

### Tab 2 - 提交的作业

- 按学期分组，含状态徽章（`已评价` / `仅AI评价` / `无评价` / `未提交`）
- 右侧工具栏排序：按班级排序、按提交时间排序、按完成度排序
- 筛选：待复审、未评价、未提交（单选项）
- 搜索无结果时显示 EmptyState 组件

### 面板 2 - 详情

- 学生信息（InfoField 组件）、AI 评价卡片（分数+问题+评语）
- 附件区（文件类型图标 + 预览/下载按钮）
- 草稿提示条（若有关联草稿）
- 教师评价展示（若已提交）

### 面板 3 - 批改

- 分数调节器（-5/-1/-0.5/+0.5/+1/+5 微调按钮 + 手动输入）
- 教师评语 textarea（自动等高调整）
- 应用 AI 评价（将 AI 问题+评语合并填入编辑器）
- 提交后自动刷新评价数据 + 涟漪特效
- **草稿系统**：编辑中自动保存到 Cookie（7 天有效期），关闭未提交时提示已保存

## 错误页面

### ForbiddenPage（403）

- 独立页面，无 MainLayout 外壳
- 检测 token → 有 token 跳转 `/`；无 token 显示"登录已过期"并跳转登录

### NotFoundPage（404）

- 独立页面，无 MainLayout 外壳
- 显示诗意提示（"欲投人处宿，隔水问樵夫"），提供返回仪表盘按钮

### LoadingPage

- 进度条动画 + 百分比显示
- 调试按钮可手动设置进度（0%/25%/50%/75%/100%）

## 全局共享外壳（MainLayout）

所有认证页面包裹在 MainLayout 中：

```
┌─ Top Bar ────────────────────────────────────────┐
│ [MagicBar 状态栏]              [头像] [主题切换]    │
├─ Left Rail ───┬─ Content ────┬─ Right Rail ──────┤
│ 仪表盘         │ <router-view> │ 排序/筛选按钮      │
│ 作业审批        │              │ （页面自定义）      │
│ 作业管理        │              │                    │
│ 班级管理        │              │                    │
└───────────────┴──────────────┴──────────────────┘
```

- MagicBar：系统主状态栏（问候语 / 状态提示 / 断连提醒 / 涟漪特效）
- Left Rail：导航项含图标 + 文字，高亮当前路由
- Right Rail：由各页面通过 `provide/inject` 动态设置按钮（排序、筛选等）
- 主题切换：亮色 / 暗色 / 自动（localStorage 持久化）

## 样式规范

- SCSS 模块化：每个 `.vue` 文件使用 `<style lang="scss" scoped>`
- 共享 mixin：`src/styles/_mixins.scss`（`@include font(...)`），通过 Vite additionalData 自动注入
- Material Design 3：CSS 自定义属性 `--md-sys-color-*`，无 UI 框架，纯手写 MD3 体系
- BEM 命名：Block `__` Element `--` Modifier

5. 路由改为 **Eager 加载**：所有页面组件在首屏一次性加载（单 bundle 256KB gzip 87KB），页面切换零延迟，不再需要网络请求拉取页面 chunk。
