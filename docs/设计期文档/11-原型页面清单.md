# 11-页面清单

## 当前主线

当前前端为 Vue 3 SPA，入口在 `frontend/`。旧 `src/main/resources/templates/` Thymeleaf 模板、`fragments/sidebar.html`、`students.html`、`works.html`、`evaluation.html`、`export.html` 已从代码主线移除。

## 路由清单

| 路由 | 页面组件 | 布局 | 说明 |
|---|---|---|---|
| `/` | 重定向 | — | 默认跳转 `/login` |
| `/login` | `LoginPage.vue` | 独立登录页 | Cookie 管理、密钥登录、写入 `auth_token` |
| `/dashboard` | `DashboardPage.vue` | `MainLayout` | 仪表盘、统计概览、趋势与评分分布 |
| `/classes` | `ClassesPage.vue` | `MainLayout` | 班级管理与花名册；学生管理归入此页 |
| `/assignments` | `AssignmentsPage.vue` | `MainLayout` | 作业管理、作业详情、Excel 导出 |
| `/review` | `ReviewPage.vue` | `MainLayout` | 作业审批、AI 流式评分、分维度评分、教师复核 |
| `/forbidden` | `ForbiddenPage.vue` | 独立错误页 | 无 `auth_token` 访问业务页时展示 |
| `/loading` | `LoadingPage.vue` | 独立过渡页 | 加载过渡和调试按钮 |
| `/:pathMatch(.*)*` | `NotFoundPage.vue` | 独立错误页 | 404 页面 |

## 认证与跳转

```text
/      -> /login
/login -> 登录成功后 /dashboard

无 auth_token:
  /dashboard /classes /assignments /review -> /forbidden

已有 auth_token:
  /login /forbidden -> /dashboard
```

## 全局外壳

认证页面统一使用 `MainLayout.vue`：

```text
Top Bar: MagicBar + 用户菜单
Left Rail: 仪表盘 / 作业审批 / 作业管理 / 班级管理
Content: router-view
Right Rail: 页面动态注入的排序、筛选、刷新等工具按钮
```

当前 UI 架构为双 Rail / MagicBar / MD3 color / Niri 布局，不再恢复旧 Sidebar。

## 页面与接口关系

| 页面 | 主要接口 |
|---|---|
| `DashboardPage.vue` | `GET /api/statistics/summary`、`GET /api/submissions`、`GET /api/evaluations`、`GET /api/students` |
| `ClassesPage.vue` | `GET /api/students`、`POST /api/students`、`DELETE /api/students/{id}`、`POST /api/dev/reset-demo-data` |
| `AssignmentsPage.vue` | `GET /api/submissions`、`GET /api/students`、`POST /api/submissions/upload`、`POST /api/export/excel` |
| `ReviewPage.vue` | `GET /api/submissions`、`GET /api/evaluations`、`GET /api/submissions/{id}/file`、`POST /api/evaluate/stream`、`POST /api/submissions/{id}/evaluation-result`、`POST /api/submissions/{id}/teacher-review` |

## 历史说明

早期设计中存在 `/students`、`/works`、`/evaluation`、`/export` 等 Thymeleaf 页面。它们只作为开发过程记录保留在早期日报和工作清单中，不作为当前计划、验收或新增开发入口。
