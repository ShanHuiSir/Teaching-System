# 原型页面清单

## 原型目录

HTML 原型系统建议放在：

```text
prototype/
```

## 页面清单

| 页面名称 | 文件名 | 主要内容 | 对应流程 |
| --- | --- | --- | --- |
| 登录页 | `login.html` | 系统名称、账号、密码、登录按钮 | 教师登录 |
| 首页 | `index.html` | 功能入口、流程概览、统计卡片 | 功能导航 |
| 学生管理页 | `students.html` | 学生表格、新增学生表单、编辑/删除入口 | 学生管理 |
| 作品提交页 | `works.html` | 学生选择、作品标题、作品类型、文件名、作品列表 | 作品提交 |
| AI 评价页 | `evaluation.html` | 作品信息、AI 分数、问题、评语、教师复核区 | AI 自动评价、教师复核 |
| 成绩统计页 | `statistics.html` | 统计卡片、成绩明细表 | 成绩统计 |
| 导出成绩页 | `export.html` | 导出条件、导出 Excel 按钮、导出结果提示 | 导出成绩 |

## 跳转关系

```text
login.html
  -> index.html
      -> students.html
      -> works.html
      -> evaluation.html
      -> statistics.html
      -> export.html
```

## 原型要求

- 先使用静态 HTML 和 CSS。
- 页面数据可以写死。
- 页面之间用链接跳转。
- 不接后端接口。
- 不做真实文件上传。
- 不做真实 Excel 导出。
- 不引入 Vue、React。
- 保持页面风格统一。
