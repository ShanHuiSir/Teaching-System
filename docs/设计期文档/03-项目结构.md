# 项目结构

## 仓库结构

```text
B1-教学评价系统/
├── docs/                 项目文档
├── prototype/            HTML 原型系统，后续创建
├── sql/                  数据库脚本
├── src/                  Spring Boot 项目源码
├── pom.xml               Maven 配置
└── README.md             项目说明
```

## 后端目录

```text
src/main/java/com/teachingeval/
├── config/               配置类，例如 OpenAPI 配置
├── controller/           控制器，负责页面路由和 API 接口
├── model/                实体类和请求/响应对象
├── repository/           数据访问层
├── service/              业务逻辑层
└── TeachingSystemApplication.java
```

## 前端页面目录

当前 Spring Boot 页面位于：

```text
src/main/resources/templates/
```

静态样式位于：

```text
src/main/resources/static/
```

HTML 原型系统建议单独放在：

```text
prototype/
```

原型阶段先用静态页面展示业务流程，后续再逐步接入 Spring Boot 接口。

## 文档目录

```text
docs/
├── 设计期文档/           业务、页面、数据库、接口方针和规范
├── 开发期文档/           日进度、数据库变更、测试和问题记录
├── 工作清单/             分工和阶段任务记录
├── interface/            早期接口说明，后续详细接口以 Swagger 为准
└── 设计规范/             早期设计规范，后续逐步迁移
```
