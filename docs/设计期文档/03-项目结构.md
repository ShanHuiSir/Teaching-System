# 03-项目结构

## 仓库顶层

```
Teaching-System/
├── src/                     # 源代码
│   └── main/
│       ├── java/com/teachingeval/   # Java 后端
│       └── resources/               # 静态资源和模板
├── sql/                     # 数据库建库脚本
├── docs/                    # 项目文档
├── .github/workflows/       # CI/CD（GitHub Actions）
├── pom.xml                  # Maven 构建配置
├── README.md                # 项目说明
└── CLAUDE.md                # AI 编码规范
```

## 后端 Java 包结构

```
com.teachingeval
├── TeachingSystemApplication.java   # Spring Boot 入口
├── config/
│   └── OpenApiConfig.java          # Swagger / OpenAPI 配置
├── controller/
│   ├── ApiExceptionHandler.java     # 全局异常处理
│   ├── EvaluationController.java    # AI 评价 + 教师评审
│   ├── HealthController.java        # 健康检查
│   ├── PageController.java          # 页面路由
│   ├── StatisticsController.java    # 成绩统计
│   ├── StudentController.java       # 学生管理
│   └── SubmissionController.java    # 作品提交管理
├── entity/
│   ├── AIEvaluationResult.java      # 评价结果实体（evaluation 表）
│   ├── Student.java                 # 学生实体（student 表）
│   └── WorkSubmission.java          # 作品提交实体（submission 表）
├── dto/
│   ├── AIEvalRequest.java              # AI 评价请求体
│   ├── ExportRow.java                  # 成绩导出 Excel 列定义
│   ├── StudentRequest.java             # 学生创建/更新请求体
│   ├── SubmissionRequest.java           # 作品提交请求体
│   ├── TeacherReviewRequest.java       # 教师评审请求体
│   └── StatisticsSummaryResponse.java  # 成绩统计响应体
├── repository/
│   ├── EvaluationRepository.java    # 评价结果数据访问
│   ├── StudentRepository.java       # 学生数据访问
│   └── SubmissionRepository.java    # 作品提交数据访问
├── service/
│   ├── AIService.java               # AI 评价服务接口
│   ├── EvaluationService.java       # 评价业务逻辑
│   ├── StatisticsService.java       # 统计业务逻辑
│   ├── StudentService.java          # 学生管理业务逻辑
│   ├── SubmissionService.java       # 作品提交业务逻辑
│   └── impl/
│       └── FakeAIService.java       # AI 评价模拟实现
```

### 分层约定

| 层      | 包              | 职责                         |
|--------|----------------|----------------------------|
| 控制器    | `controller`   | 接收 HTTP 请求，参数校验，调用 Service |
| 服务接口   | `service`      | 定义业务能力抽象                   |
| 服务实现   | `service.impl` | 业务逻辑实现                     |
| 实体     | `entity`       | JPA 实体，对应数据库表              |
| 数据传输对象 | `dto`          | 请求体 / 响应体，不绑定数据库           |
| 数据访问   | `repository`   | Spring Data JPA 接口         |

## 前端资源

```
src/main/resources/
├── application.properties    # Spring Boot 配置
├── static/
│   └── style.css             # 全局样式（Material Design 3）
└── templates/
    ├── login.html            # 登录页
    ├── students.html         # 学生管理页
    ├── evaluation.html       # 作品评价页（AI 评价 + 教师评审）
    ├── works.html            # 作品提交页
    └── export.html           # 成绩导出页
```

前端使用 Thymeleaf 模板引擎渲染，样式遵循 Material Design 3 规范。

## 数据库

```
sql/
└── schema.sql    # MySQL 建库脚本（student / submission / evaluation 三张表）
```

当前开发期使用 H2 内存数据库，schema.sql 为正式环境的 MySQL 脚本。
