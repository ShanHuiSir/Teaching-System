# 阶段计划与范围边界

## 阶段计划

| 阶段 | 主要内容 | 目标 |
| --- | --- | --- |
| 第一阶段 | 设计期文档和 HTML 原型 | 先把业务流程、页面和数据关系讲清楚 |
| 第二阶段 | 学生管理和作品提交基础功能 | 完成学生信息维护和作品登记 |
| 第三阶段 | FakeAIService 模拟 AI 评价 | 先用假 AI 跑通评价流程 |
| 第四阶段 | 教师复核和成绩统计 | 保存教师最终评分并展示统计结果 |
| 第五阶段 | Excel 导出 | 导出最终成绩表 |
| 第六阶段 | 接入真实大模型 | 将 FakeAIService 替换为真实 AI 接口 |

## 当前阶段范围

当前阶段重点完成：

- 设计期文档。
- HTML 原型页面。
- 业务流程说明。
- 页面和文档对应关系。

## 当前阶段暂不做

- 不做真实大模型调用。
- 不做真实 Excel 文件导出。
- 不做复杂权限系统。
- 不做学生端和管理员端。
- 不做复杂部署和线上演示依赖。

## 后续实现原则

- 先按 HTML 原型确认业务流程。
- 再逐步把页面接入 Spring Boot 接口。
- 详细接口以 Swagger / OpenAPI 为准。
- 每次功能变化同步更新相关文档。
