# 数据库设计

## 设计目标

数据库用于保存学生信息、作品提交记录、AI 评价结果和教师最终评价结果。当前阶段先满足教师端最小业务闭环，后续再扩展真实文件上传、Excel 导出和真实大模型调用记录。

## 核心表

| 表名 | 作用 |
| --- | --- |
| `student` | 保存学生基础信息 |
| `submission` | 保存学生作品提交记录 |
| `ai_evaluation_result` | 保存 AI 评价结果和教师最终评价 |

## student 学生表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT | 主键 |
| `student_no` | VARCHAR(32) | 学号，唯一 |
| `name` | VARCHAR(64) | 学生姓名 |
| `class_name` | VARCHAR(64) | 班级 |

## submission 作品提交表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT | 主键 |
| `student_id` | BIGINT | 学生 ID |
| `student_name` | VARCHAR(64) | 学生姓名快照 |
| `title` | VARCHAR(128) | 作品标题 |
| `file_name` | VARCHAR(512) | 作品文件名 |
| `work_type` | VARCHAR(32) | 作品类型 |
| `remark` | TEXT | 备注 |
| `submitted_at` | DATETIME | 提交时间 |

## ai_evaluation_result 评价结果表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT | 主键 |
| `submission_id` | BIGINT | 作品提交 ID |
| `ai_score` | DECIMAL(5,2) | AI 建议分数 |
| `ai_issues` | TEXT | AI 发现的问题 |
| `ai_comment` | TEXT | AI 评语 |
| `teacher_score` | DECIMAL(5,2) | 教师最终分数 |
| `teacher_comment` | TEXT | 教师最终评语 |
| `status` | TINYINT | 状态：0 未评价，1 AI 已评价，2 教师已确认 |

## 表关系

```text
student 1 ---- N submission 1 ---- 1 ai_evaluation_result
```

- 一个学生可以有多份作品提交。
- 一份作品提交对应一份评价结果。
- AI 分数是系统建议，最终成绩以教师确认分数为准。
