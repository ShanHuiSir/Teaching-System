# 数据库字段设计

## student 表

保存学生基础信息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| student_no | VARCHAR(50) | 学号 |
| name | VARCHAR(50) | 姓名 |
| class_name | VARCHAR(100) | 班级 |
| phone | VARCHAR(30) | 手机号，可选 |
| created_at | DATETIME | 创建时间 |

## evaluation 表

保存作品、AI 评价和教师最终评价。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| student_id | INTEGER | 学生 ID |
| work_title | VARCHAR(100) | 作品标题 |
| file_name | VARCHAR(255) | 上传文件名 |
| ai_score | INTEGER | AI 建议分数 |
| ai_problems | TEXT | AI 发现的问题 |
| ai_comment | TEXT | AI 评语 |
| final_score | INTEGER | 教师最终分数 |
| final_comment | TEXT | 教师最终评语 |
| status | VARCHAR(30) | 状态：未评价、已评价、已确认 |
| created_at | DATETIME | 创建时间 |

## 建表 SQL 草稿

```sql
CREATE TABLE student (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  student_no VARCHAR(50) NOT NULL,
  name VARCHAR(50) NOT NULL,
  class_name VARCHAR(100) NOT NULL,
  phone VARCHAR(30),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE evaluation (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  student_id INTEGER NOT NULL,
  work_title VARCHAR(100),
  file_name VARCHAR(255),
  ai_score INTEGER,
  ai_problems TEXT,
  ai_comment TEXT,
  final_score INTEGER,
  final_comment TEXT,
  status VARCHAR(30) DEFAULT '未评价',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
