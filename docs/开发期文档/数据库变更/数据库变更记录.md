## 2026-06-01

### 变更原因

第 8 天将真实文件上传从后续计划前移到当前任务，需要在作品提交记录中保存真实文件的服务器路径、大小和 MIME 类型，方便后续 Java 调 Py 侧预处理服务。

### 变更内容

- 修改表：`submission`
- 新增字段：
  - `file_path VARCHAR(1024)`：服务器保存路径。
  - `file_size BIGINT`：文件大小，单位字节。
  - `content_type VARCHAR(128)`：文件 MIME 类型。

### 影响范围

- 新增接口 `POST /api/submissions/upload` 会写入这些字段。
- 旧接口 `POST /api/submissions` 仍可只保存作品元数据和文件名，这三个字段允许为空。
- H2 开发库由 JPA `ddl-auto=update` 自动补字段；正式 MySQL 建表脚本已同步更新。
