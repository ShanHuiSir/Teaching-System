### 4. 真实 AI 稳定化结论

已确认：

- Java/AI health 通过。
- AI preprocess 通过。
- 真实 AI `/api/evaluate/real` 已能返回 `aiScore/aiIssues/aiComment`。
- Java 侧已有 `DelegatingAIService` 和 `RealAIService`：
  - `app.ai.real.enabled=false` 时使用 FakeAI。
  - `app.ai.real.enabled=true` 时调用 Py `/api/evaluate/real`。
  - 真实 AI 调用异常时自动降级为 FakeAI。

最终验收口径：

- 能力层面：真实 AI 已接通。
- 稳定性层面：演示默认关闭真实 AI，避免 Key、网络或模型服务波动影响主流程。
- 展示层面：如需演示真实评分，可以临时开启配置并准备固定样例。

### 5. 前端最终版保留判断

最终版不建议直接采用未经回归的 #73 基线。

可保留候选：

| 内容 | 条件 |
| --- | --- |
| 评价页步骤化展示 | 不改 API、不改路由、不引入认证或班级依赖 |
| 学生页新增/删除体验 | 只使用已有 `/api/students` 接口 |

| 局部样式统一 | 只修明显错位、遮挡、移动端溢出 |

暂不纳入最终演示：

| 内容 | 原因 |
| --- | --- |
| LoginPage 整体替换 | 完整认证权限未配套 |
| ClassSelectionPage | 缺少 `/user/classes` 和班级上下文 |

| Cookie 认证迁移 | 会改变当前固定教师账号演示口径 |
