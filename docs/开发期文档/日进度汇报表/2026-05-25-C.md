- - `/api/submissions/{submissionId}/teacher-review`
- - `/api/submissions/{submissionId}/evaluate`
- - `/api/submissions/{submissionId}/evaluation`
- `AIService`：**接口**，后续接入Ai服务时，利用此interface新建即可

- `EvaluationController`：目前有以下接口：
- - `POST` `/api/submissions/{submissionId}/teacher-review`
- - `POST` `/api/submissions/{submissionId}/evaluate`

### 如何实现
DI时，`FakeAIService`注册实例，`EvaluationController`调用此实例。（假AI服务）

利用`PostMapping`创建接口`/api/submissions/{submissionId}/teacher-review`，将`submissionId`作为路径变量传入形参中。
`submissionRepository`实例（`SubmissionRepository`类型）会检查传入的`submissionId`，如果不存在则返回`IllegalArgumentException`。

由于SpringBoot的注入机制，执行以下代码时：
```java
public class EvaluationService {
    public EvaluationService(AIService aiService,
        this.aiService = aiService;
        ...
    AIEvaluationResult result = aiService.evaluate(request);
```
`aiService`会被已经实例化的`FakeAIService`替换。

执行以下代码时：
```java
public AIEvaluationResult evaluate(Long submissionId, AIEvalRequest request) {
    submissionRepository.findById(submissionId)
            .orElseThrow(() -> new IllegalArgumentException("作品提交不存在"));

    AIEvaluationResult result = aiService.evaluate(request);
    AIEvaluationResult saved = evaluationRepository.findBySubmissionId(submissionId)
            .orElseGet(AIEvaluationResult::new);

    saved.setSubmissionId(submissionId);
    saved.setAiScore(result.getAiScore());
    saved.setAiIssues(result.getAiIssues());
    saved.setAiComment(result.getAiComment());
    saved.setStatus(1);
    return evaluationRepository.save(saved);
}
```
查找提交表仓库，如果有匹配的submissionId则继续，没有则发出异常。

利用实例化的FakeAIService，得到AI结果。

查找AI评价仓库，匹配则返回`AIEvaluationResult`实体，`orElseGet`不执行。 不匹配则创建并返回`AIEvaluationResult`实体。

设置属性，其中submissionId与提交表仓库保持一致。

`.save(saved)`返回被持久化的评价表仓库实体。

完整链路:
```
evaluationRepository.save(saved)        → return AIEvaluationResult（持久化后）
↑
EvaluationService.evaluate()     → return 给 Controller
↑
EvaluationController.evaluate()         → @RestController 自动将对象序列化为 JSON
↑
HTTP Response Body                      → 前端拿到 JSON 渲染到页面
```
