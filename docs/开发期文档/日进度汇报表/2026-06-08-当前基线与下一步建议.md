# 2026-06-08 当前基线与下一步建议

## 当前主线

当前项目以 `main` 分支为唯一基线。旧 `codex/d11-final-stabilization` 分支已不再作为参考。

前端已经进入新版教师工作台：

- `/` 默认跳转 `/login`
- `/dashboard` 为仪表盘
- `/classes` 为班级管理，学生管理归入班级和花名册
- `/assignments` 为作业管理，Excel 导出归入作业管理
- `/review` 为作业审批、AI 评价和教师复核
- 无 token 访问业务页跳转 `/forbidden`
- UI 采用双 Rail / MagicBar / MD3 color / Niri 布局

以下旧内容不再作为任务来源：

- 旧 Thymeleaf 页面
- 旧 `Sidebar.vue`
- 独立学生页
- 独立导出页
- `/students`、`/works`、`/evaluation`、`/export` 作为页面路由的旧口径

说明：`/api/students`、`/api/export/excel` 等仍是后端 REST API，不属于旧页面。

## 最新风险

| 优先级 | 风险 | 说明 |
|---|---|---|
| P0 | 正式业务模型不足 | 当前班级和作业主要由 `student.className`、`submission.workType` 派生，前端已经像正式系统，后端模型仍偏原型 |
| P0 | 提交与作业关系缺失 | `submission` 还没有正式 `assignmentId`，后续作业筛选、导出、打回、补交会受限 |
| P0 | 多文件策略未定 | 当前提交表只适合单文件；多文件应在"压缩包约定"和"附件表"之间二选一 |
| P1 | 评价时间和草稿字段不足 | `evaluation` 缺少 AI/教师评价创建与更新时间，云端草稿尚未设计 |
| P1 | 导出筛选不足 | 当前导出全部成绩，不支持按班级、作业、学生、状态筛选 |
| P1 | 预览/下载体验待补齐 | `ReviewPage` 的文件预览、下载、文件类型和文件大小应与后端元数据打通 |
| P2 | 认证仍为演示账号 | 可以保留演示登录，但正式账号表和权限边界需要后续设计 |
