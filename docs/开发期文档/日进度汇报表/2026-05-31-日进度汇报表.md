### 3. 修复演示数据重置硬编码 ID 问题

发现问题：

- `DataInitializer.resetDemoData()` 原先依赖固定学生 ID 和作业 ID。
- H2 自增主键在 `deleteAll()` 后不一定回到 1。
- 多次重置演示数据或自动化测试重复执行时，评价记录可能关联到不存在的作业。

处理方式：

- `seedStudents()` 返回实际保存后的学生列表。
- `seedSubmissions()` 使用学生实体真实 `id` 和 `name` 建立作业关联。
- `seedEvaluations()` 使用实际保存后的作业 `id` 建立评价关联。
- 自动化测试中新增作业前通过学生分页接口读取真实学生 ID。
