## 今日已完成

### 1. 任务范围和接口字段已对齐

今日明确了以下规则：

- 前端成功响应暂时使用裸数据，不统一包裹 `code/message/data`。
- 失败响应由全局异常处理返回 `{ "message": "错误原因" }`。
- 新增学生只传 `studentNo`、`name`、`className`。
- 新增作业只传 `studentId`、`title`、`fileName`、`workType`、`remark`。
- `id`、`studentName`、`submittedAt`、`status` 等字段由后端维护。

这样可以减少前后端字段不一致导致的联调问题。

## 当前发现的问题

### 1. 真实 AI 尚未接入

当前 AI 评价通过 `FakeAIService` 返回模拟结果。前端已经调用后端 AI 评价接口，但后端实现还不是真实大模型。

后续需要评估：

- 使用哪个大模型服务。
- API Key 如何配置。
- Prompt 如何设计。
- 失败时是否回退到 FakeAIService。

### 2. 真实文件上传尚未实现

当前作业提交主要保存文件名和作业信息，尚未保存真实文件。

后续需要明确：

- 文件保存目录。
- 文件大小限制。
- 支持的文件类型。
- 数据库是否保存文件路径。

### 3. Excel 导出仍是占位能力

当前导出接口返回示例文件地址，还没有生成真实 Excel 文件。

后续需要实现：

- 汇总学生、作业、AI 评价和教师评分。
- 生成 Excel 文件。
- 返回可下载文件。

### 4. 后端校验还需要加强

当前已有部分 Service 层校验，但还不系统。

后续建议：

- 新增 `CreateStudentRequest`。
- 新增 `CreateSubmissionRequest`。
- 使用 `@NotBlank`、`@NotNull`、`@Valid` 等校验。
- 统一参数校验异常处理。
