## 遇到的问题

### 1. Maven 启动时出现旧编译产物冲突

启动时曾出现 `com.teachingeval.entity.Student` 和 `com.teachingeval.model.Student` 实体名重复的问题。

原因是旧的 `target/classes` 中残留了已删除或移动过的类。

处理方式：

```text
mvn clean spring-boot:run
```

清理旧编译产物后可以正常启动。

### 2. PR #39 存在冲突

PR #39 与 `main` 在以下文件发生冲突：
