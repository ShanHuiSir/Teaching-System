### 1. DeepSeek 真实评分接入

将 AI 评分逻辑从 `docxconv/evaluator.py`（已删除）迁移到独立包 `Evaluator/`：

```
Evaluator/
├── pyproject.toml
└── src/evaluator/
    └── deepseek.py
```

- `deepseek.py` 通过 OpenAI 兼容 API 调用 DeepSeek，所有参数从 `config.py` 读取。
- `/api/evaluate/real` 行为变更：`file → preprocess → evaluate_content(extractedText, studentName) → JSON`。
- 空文本返回 `aiScore=0` + 提示；API 异常返回 503；JSON 解析失败返回降级结果。

4 组样本实测：

| 样本 | 字数 | aiScore | 简评 |
|---|---|---|---|
| SimpleTest.docx（简单框架） | ~50 | 65 | 内容过于简略，列表格式混乱 |
| TableTest.docx（活动备案表） | 1596 | 72 | 活动名称与内容不符，结构混乱 |
| DifficultTest.docx（职业规划书） | 7532 | 78 | 结构完整但计划部分缺失 |
| student_essay.txt（AI教育论文） | 637 | 85 | 结构清晰但深度不足 |

### 3. Py 侧 Swagger 文档完善

### 4. Java-Python Swagger 合并

新增 `AiDocsProxyController.java`：

- `GET /v3/ai-docs` 代理转发 `http://localhost:8000/openapi.json`。

- 通过 `@PostConstruct` 程序化注入 `SwaggerUiConfigProperties`，注册双分组：`Java 教学系统` / `AI 服务`。

效果：打开 `http://localhost:8080/swagger-ui/index.html`，顶部下拉菜单可切换 Java 后端和 Python AI 服务的全部接口。
