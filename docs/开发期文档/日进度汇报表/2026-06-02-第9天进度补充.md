### 2. 补齐 Py 侧预处理状态字段

修改：

- `ai-service/DocxConv/src/docxconv/server.py`

完成内容：

- `PreprocessResponse` 新增：

```json
{
  "renderStatus": "ok / degraded / failed / none",
  "renderEngine": "libreoffice / word / onlyoffice / none",
  "renderWarnings": []
}
```

- 非 DOCX 文件默认返回 `renderStatus=none`、`renderEngine=none`。
- DOCX 文件会尝试使用 LibreOffice 渲染。
- LibreOffice 渲染成功时返回 `renderStatus=degraded`，提示复杂排版可能与 Word 存在差异。
- LibreOffice 渲染失败时返回 `renderStatus=failed`，但不阻断结构化文本提取。
- `/api/evaluate/real` 继续带出预处理中的渲染状态字段。
- 将 `studentName` 改为 multipart form 字段，方便 Java 真实 AI 客户端调用。

### 3. 新增 Java 真实 AI 调用能力

新增：

- `src/main/java/com/teachingeval/service/impl/RealAIService.java`
- `src/main/java/com/teachingeval/service/impl/DelegatingAIService.java`

修改：

- `AIService`
- `EvaluationService`
- `FakeAIService`
- `application.properties`

完成内容：

- 新增配置：

```properties
app.ai.real.enabled=false
app.ai.real.endpoint-url=http://localhost:8000/api/evaluate/real
app.ai.real.connect-timeout-ms=3000
app.ai.real.read-timeout-ms=30000
```

- 默认仍使用 `FakeAIService`，保证离线演示和原主流程稳定。
- 开启 `app.ai.real.enabled=true` 后，Java 会把真实文件以 multipart 方式发送给 Py `/api/evaluate/real`。
- Py 返回的 `aiScore`、`aiIssues`、`aiComment`、`status` 会映射为 Java `EvaluationResult` 并落库。
- 真实 AI 调用失败时自动降级为模拟评价，避免主流程崩溃。
