## 2026-05-27

### 问题一：启动时报旧实体类冲突

### 问题

运行项目时出现 `com.teachingeval.entity.Student` 和 `com.teachingeval.model.Student` 实体名重复的问题。

### 影响

项目无法正常启动，影响当天基础版本验收。

### 原因分析

源码中已经以 `entity/Student.java` 为准，但旧编译产物中仍残留 `model/Student.class`，导致 Hibernate 扫描到两个实体名都为 `Student` 的类。

### 解决办法

执行：

```bash
mvn clean spring-boot:run
```

清理 `target/` 旧编译产物后重新启动。

### 当前状态

已解决。

## 2026-05-27

### 问题二：PR #39 与 main 存在 sidebar.html 冲突

### 问题

PR #39 合并时提示以下文件冲突：

```text
src/main/resources/templates/fragments/sidebar.html
```

### 影响

PR #39 无法直接合并到 `main`，影响 B 同学作业状态入口拆分功能进入主分支。

### 原因分析

`main` 中已经调整过侧边栏导航，PR #39 也修改了同一段导航结构，导致 Git 无法自动判断应该保留哪些入口。

### 解决办法

- 基于 `origin/main` 创建 `codex/resolve-pr-39` 分支。
- 本地合并 PR #39 并手动解决冲突。
- 保留 PR #39 中“未审批 / AI 已审批 / 已完成”三个状态入口。
- 保留 `main` 中已有的“学生管理 / 作业提交 / 导出成绩”入口。
- 运行 `mvn test` 验证通过。
- 通过 PR #40 合并到 `main`。

### 当前状态

已解决。

## 2026-05-27

### 问题三：8080 端口被旧 Java 进程占用

### 问题

验收时运行 `mvn spring-boot:run`，提示 `Port 8080 was already in use`。

### 影响

项目无法使用默认端口 8080 启动，影响接口和页面验收。

### 原因分析

本机已有旧 Java 进程监听 8080 端口。

### 解决办法

- 临时使用 8081 启动项目进行验收。
- 验收结束后关闭临时 8081 服务。
- 后续如需使用 8080，需要先关闭旧 Java 进程。

### 当前状态

暂时绕过。

## 2026-05-28

### 问题一：本地 main 落后远端 main

### 问题

第 4 天检查时发现本地 `main` 落后 `origin/main` 4 个提交。

### 影响

如果直接在旧本地代码上验收，可能遗漏远端已经合入的文档和分支处理结果。

### 原因分析

远端在检查过程中合入了旧 review 分支，`origin/main` 已推进到最新提交。

### 解决办法

执行：

```bash
git pull --ff-only
```

将本地 `main` 快进到最新远端版本。

### 当前状态

已解决。

## 2026-05-28

### 问题二：学生管理页操作入口容易误导

### 问题

学生管理页操作菜单中原有“评价”入口只携带学生信息，未携带具体 `submissionId`，进入评价页后无法直接评价具体作业。

### 影响

主流程演示时容易从学生管理页直接进入空评价页，造成流程断点。

### 原因分析

评价页以作业提交为评价对象，需要从具体作业记录进入，而不是只从学生进入。

### 解决办法

将学生管理页操作入口从“评价”改为“作业”，并跳转到：

```text
/submit?studentId={id}
```

让教师先为学生提交或选择作业，再从作业状态页进入评价。

### 当前状态

已解决。

## 2026-05-28

### 问题三：部分页面文案仍保留“作业列表”

### 问题

评价页空状态和作业相关页面仍使用“作业列表”表述，与当前侧边栏拆分后的“未审批 / AI 已审批 / 已完成 / 作业提交”入口不完全一致。

### 影响

影响演示时对页面入口的解释，容易让老师误以为仍有一个独立的作业列表入口。

### 原因分析

第 3 天合并作业状态入口拆分后，部分提示文案未同步更新。

### 解决办法

- 将 `works.html` 页面标题调整为“作业提交记录”。
- 将评价页空状态提示调整为从“未审批 / AI 已审批 / 作业提交记录”进入。
- 将 JS 错误提示统一为“作业提交记录加载失败”。

### 当前状态

已解决。
