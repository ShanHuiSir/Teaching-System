## 2026-05-27

### 问题一：启动时报旧实体类冲突

### 问题

运行项目时出现 `com.teachingeval.entity.Student` 和 `com.teachingeval.model.Student` 实体名重复的问题。

### 影响

项目无法正常启动，影响当天基础版本验收。

### 原因分析

源码中已经以 `entity/Student.java` 为准，但旧编译产物中仍残留 `model/Student.class`，导致 Hibernate 扫描到两个实体名都为 `Student` 的类。

### 解决办法

执行：

```bash
mvn clean spring-boot:run
```

清理 `target/` 旧编译产物后重新启动。

### 当前状态

已解决。

## 2026-05-27

### 问题二：PR #39 与 main 存在 sidebar.html 冲突

### 问题

PR #39 合并时提示以下文件冲突：

```text
src/main/resources/templates/fragments/sidebar.html
```

### 影响

PR #39 无法直接合并到 `main`，影响 B 同学作业状态入口拆分功能进入主分支。

### 原因分析

`main` 中已经调整过侧边栏导航，PR #39 也修改了同一段导航结构，导致 Git 无法自动判断应该保留哪些入口。

### 解决办法

- 基于 `origin/main` 创建 `codex/resolve-pr-39` 分支。
- 本地合并 PR #39 并手动解决冲突。
- 保留 PR #39 中“未审批 / AI 已审批 / 已完成”三个状态入口。
- 保留 `main` 中已有的“学生管理 / 作业提交 / 导出成绩”入口。
- 运行 `mvn test` 验证通过。
- 通过 PR #40 合并到 `main`。

### 当前状态

已解决。

## 2026-05-27

### 问题三：8080 端口被旧 Java 进程占用

### 问题

验收时运行 `mvn spring-boot:run`，提示 `Port 8080 was already in use`。

### 影响

项目无法使用默认端口 8080 启动，影响接口和页面验收。

### 原因分析

本机已有旧 Java 进程监听 8080 端口。

### 解决办法

- 临时使用 8081 启动项目进行验收。
- 验收结束后关闭临时 8081 服务。
- 后续如需使用 8080，需要先关闭旧 Java 进程。

### 当前状态

暂时绕过。
