# 部署文档使用指南

## 如何使用这些文档

### 第一步：确定您的场景

根据您的使用目的选择对应的文档：

| 您的需求 | 阅读文档 | 说明 |
|---------|----------|------|
| **验收演示** | [01-麒麟LoongArch虚拟机部署指南](01-麒麟LoongArch虚拟机部署指南.md) | 详细说明如何在 LoongArch 麒麟虚拟机中部署和录屏 |
| **快速启动** | [部署快速指南](部署快速指南.md) | 快速查阅启动命令和常见问题 |
| **全面了解** | [02-部署方案汇总](02-部署方案汇总.md) | 了解所有部署方式、配置和问题解决方案 |
| **文档导航** | [00-部署文档目录](00-部署文档目录.md) | 了解文档结构和使用建议 |

### 第二步：执行部署

根据文档中的步骤执行部署。

### 第三步：验证部署

使用健康检查命令验证服务是否正常运行：

```bash
curl http://localhost:8080/api/health
curl http://localhost:8000/api/health
curl -I http://localhost:5173
```

### 第四步：访问系统

打开浏览器访问：

```
http://localhost:5173
```

登录账号：`teacher / 123456`

## 常见问题

### 1. 端口被占用

```bash
fuser -k 8080/tcp 5173/tcp 8000/tcp
```

### 2. Maven 编译失败

```bash
mvn clean compile -DskipTests
```

### 3. npm 安装慢

```bash
npm config set registry https://registry.npmmirror.com
```

### 4. AI 服务未启动

后端 `demo` 配置已关闭真实 AI 调用，使用 `FakeAIService` 降级返回演示评分（82.50 分），不影响主流程演示。

## 录屏演示流程（验收必需）

1. **证明运行环境**：
   ```bash
   uname -m
   cat /etc/os-release
   ```

2. **启动项目**：
   ```bash
   ./start-kylin-loongarch-demo.sh
   ```

3. **检查服务**：
   ```bash
   curl http://localhost:8080/api/health
   curl -I http://localhost:5173
   ```

4. **浏览器访问**：
   ```
   http://localhost:5173
   ```

5. **功能演示主线**：
   ```
   登录 → 仪表盘 → 作业审批 → 附件预览/下载 → AI评价 → 教师复核 → 作业管理 → Excel导出
   ```
