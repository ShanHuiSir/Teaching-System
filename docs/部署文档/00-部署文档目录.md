## 文档说明

### 部署方案汇总.md

适用于所有部署场景的完整指南，包括：

- **4 种部署方式**：
  1. 原生启动（推荐用于验收）
  2. Docker Compose 部署
  3. 手动启动三服务
  4. 一键启动脚本

- **配置文件详解**：Spring Boot 多环境配置、关键配置项说明

- **健康检查**：后端、AI 服务、前端的检查方法

- **常见问题**：端口占用、编译失败、npm 安装慢等解决方案

- **录屏演示流程**：验收录屏的标准流程建议

- **CI/CD 部署**：GitHub Actions 自动部署配置

## 使用建议

### 验收演示场景

1. 先阅读 **麒麟LoongArch虚拟机部署指南.md**，了解验收要求
2. 按照指南准备虚拟机环境
3. 参考 **部署方案汇总.md** 的"方式一：原生启动"章节执行部署
4. 按照"录屏演示建议流程"录制验收视频

### 日常开发场景

直接参考 **部署方案汇总.md** 的"方式三：手动启动三服务"或"方式四：一键启动脚本"。

### 服务器部署场景

参考 **部署方案汇总.md** 的"方式二：Docker Compose 部署"，并根据实际情况配置 Nginx 反向代理和 HTTPS。
