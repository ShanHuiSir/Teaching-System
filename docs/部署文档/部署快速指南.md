## 二、快速启动命令

### 1. 验收演示（LoongArch 麒麟虚拟机）

```bash
# 验证环境
uname -m              # 应为 loongarch64
cat /etc/os-release   # 应为麒麟系统

# 启动
chmod +x start-kylin-loongarch-demo.sh
./start-kylin-loongarch-demo.sh

# 访问
http://localhost:5173
登录账号：teacher / 123456
```

### 2. 日常开发（手动启动三服务）

```bash
# 终端 1：启动 AI 服务（可选）
cd ai-service
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e DocxConv -e Evaluator -e ScreenshotProc -e ArchiveProc
python -m docxconv serve --host 0.0.0.0 --port 8000

# 终端 2：启动后端
cd Teaching-System
mvn compile
mvn spring-boot:run

# 终端 3：启动前端
cd frontend
npm install
npm run dev

# 访问
http://localhost:5173
```

### 3. 快速测试（一键启动）

**Windows：**
```bash
start.bat
```

**Linux/macOS：**
```bash
./start.sh
```

### 4. 生产环境（Docker Compose）

```bash
# 配置环境变量
cat > .env << EOF
DEEPSEEK_API_KEY=你的API密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
EOF

# 构建并启动
mvn -DskipTests package
docker compose up --build -d

# 查看状态
docker compose ps

# 访问
http://localhost:5173
```

## 三、健康检查

```bash
# 后端
curl http://localhost:8080/api/health

# AI 服务
curl http://localhost:8000/api/health

# 前端
curl -I http://localhost:5173
```

## 四、常见问题

### 端口被占用
```bash
fuser -k 8080/tcp 5173/tcp 8000/tcp
```

### Maven 编译失败
```bash
mvn clean compile -DskipTests
```

### npm 安装慢
```bash
npm config set registry https://registry.npmmirror.com
```
